## ⛔ LAWS & TRAPS (binding)
- **A LAW DERIVED FROM ONE REGISTER'S MECHANISM DOES NOT BIND THE OTHERS (s14):** the s8 law (*"NEVER CARRY A VALUE IN A CLAIMED REGISTER ACROSS A CROSSING"*) was generalised from r9's mechanism (seed-restore: writeback deleted, reload preserved) to the whole claimed set. It is FALSE of r8/r10/r11 at HEAD — the round-trip class does save/restore exactly. The law is true of r9 and the arg tier; amended to a convention backed by a gate, not a fact about the machine. Generalises s13's *"A MECHANISM-DERIVED LAW INHERITS THE MECHANISM'S SCOPE"* to register classes as well as rungs.
- **A PRESENCE CHECK RUN ONLY AT OPEN MEASURES ARRIVAL ORDER, NOT OCCUPANCY (s15):** any mutual-visibility signal must be re-read at the instant of the action it protects. Read once at session open it answers a different question than the one asked: the later seat always detects, the earlier seat (which holds the tree, is mid-flight) never does. Re-check before each commit and before push; re-`touch` per rung. Same class as the macro-blind assembly census and the LD_AUDIT complement — an instrument returning a clean answer to a question nobody asked, and an empty answer never checked against a known non-empty control.
- **A GATE RESOLVING ITS TARGET BY ABSOLUTE PATH GRADES WHATEVER SITS AT THAT PATH, NOT THE TREE THE SESSION IS EDITING (s15):** 23/71 gates hardcode `/home/claude/…`; 0/71 use `git rev-parse`. Under multi-seat reality a gate run in a clone audits the peer's worktree and reports the verdict as the current seat's own — directly undermining the HEAD-stamp-every-measurement requirement. Fix: `ROOT=$(git rev-parse --show-toplevel)` once per gate; copy `omega_own_k`'s `TOTAL_FILES -eq 0 → exit 1` positive control into every absence-asserting gate. Fix not yet applied (191 sites, three goals' territory).
- **A KILLSWITCH IS NOT A GATE UNTIL SOMETHING CALLS THE ARM IT GUARDS (s13):** a `#define` that is live, guarded, `-D`-overridable and correct can still be DECORATIVE if its arm has no call sites — `RTCC_GLOBAL_R8_ANCHOR` is exactly that. Before A/B-ing any killswitch, **grep the arm for callers AND confirm the ON form appears in emitted output**; the encoder arm existing is not the arm firing. Three RC-5 numbers have now been voided by three DIFFERENT mechanisms of one class: same binary (s9), noise below floor (s10/s11), unreachable arm (s13).
- **A POSITIVE CONTROL IN THE SAME EMISSION IS THE CHEAPEST GUARD AGAINST A NULL (s13):** "ANCHOR greps to zero" is ambiguous alone; GVA firing 106 times in the IDENTICAL `.s` is what converts it into a measurement. Any census reporting a zero must name the non-zero it measured alongside it. (Generalizes s11's "check the census against a quantity you already know".)
- **A MECHANISM-DERIVED LAW INHERITS THE MECHANISM'S SCOPE (s13):** "RC-5 has zero dynamic delta" is true of GVA's mechanism (same load, encoding-only) and was carried across the whole rung; ANCHOR's mechanism removes 2 instructions AND a dependent load (17B→3B). Attach mechanism laws to the mechanism, never to the rung number.
- **AN UNCOMMITTED WORKTREE IS NOT A STRANDING SIGNAL WHEN ANOTHER SEAT MAY BE LIVE (s11/s12):** two seats ran concurrently on ONE filesystem on 2026-08-10; s12 read s11's mid-flight worktree at 19:51 as an abandoned session (s11 committed at 19:59). `git status --porcelain` cannot distinguish "abandoned" from "in progress". Check commit TIMESTAMPS and whether HEAD is still moving before recovering another seat's tree; never conclude abandonment from worktree state alone. The concurrency protocol assumes one seat per tree -- when that is violated, neither seat can see the other.
- **A STATIC CALL-SITE RANK IS NOT A HOTNESS RANK — FOURTH OCCURRENCE, AND THE SHARPEST (s11):** `rt_arg_stage` and `rt_call_arr` sit **1.36x** apart statically (1031 vs 760 emitted sites) and **673,000x** apart dynamically on fibonacci. The mechanism is structural — hot code is loop-resident and needs ONE call site, cold setup code needs many — so a `grep -c` over `.s` files measures roughly the INVERSE of the quantity it is quoted as. Any rung ordered "by hotness" whose evidence is a static count is aimed backwards.
- **THERE IS NO SINGLE HOTNESS RANK (s11):** the hot crossing set is WORKLOAD-DEPENDENT and the workloads share almost nothing (`rt_call_arr`: 4 on fibonacci, 100,005 on roman). A ranking is meaningless without a STATED workload mix; a single benchmark's rank misranked by 10^5 here.
- **AN INSTRUMENT CAN RETURN THE EXACT COMPLEMENT OF WHAT YOU ASKED (s11):** `LD_AUDIT`/`la_pltenter` on mode-3 measures intra-C PLT traffic, NOT generated->C crossings, because the RX slab has no PLT — yielding an exact INVERSE correlation with the emitted call sites. The tell was the answer being TOO CLEAN (five straight zeros is a property of the instrument, not the program). **Before trusting any census, check it against a quantity you already know** — here, emitted call sites in the `.s`.
- **INTERLEAVE, OR DO NOT COMPARE (s11):** two arms measured in BLOCKS confound the arm with thermal/scheduler drift; on this 1-core box that confound INVERTED the conclusion (sequential said ASLR-pinning was 2x worse; interleaved said the arms are indistinguishable). Every two-arm comparison alternates run-by-run.
- **PINNING CONVERTS VARIANCE INTO BIAS, IT DOES NOT REMOVE IT (s11):** `setarch -R` yields ONE layout, not the average layout, and a single layout can be systematically unlucky (~5% slow here). Justified for RATIOS (shared layout cancels between arms); the "reduces spread" claim is FALSIFIED (on 1.075x vs off 1.085x, N=12 interleaved).
- **AN INSTRUMENT THAT FAILS ITS OWN EXIT CRITERION CANNOT GRADE A RUNG (s11):** RC-0(a) demands max/min <= 1.05x on an unchanged binary; this box gives 1.075-1.085x. Every rung graded on this rail below ~1.09x is UNGRADED whatever number it printed.
- **`cmd | grep -q` UNDER `pipefail` IS A DEFECT WHEN THE UPSTREAM IS EXTERNAL (s11):** the reader's early exit SIGPIPEs the upstream and pipefail propagates it, so a MATCH READS AS A MISS. Deterministic above the 64KiB pipe buffer, a scheduling race below it. Portable form is `grep -c` + a count test; `grep -q FILE` (no pipe) is always safe. The discriminator is the UPSTREAM, not the `-q`.
- **CONTENT, NOT HASH, IS THE TEST FOR "DID IT LAND" (s11):** rebase at handoff rewrites hashes, so an absent hash is not absent work -- and a present hash in a cursor is not present work. Verify by grepping for the artifact.
- **A PUSHED FINDING IS NOT A PUSHED FIX (s11):** repos push separately and can diverge; `.github` landing while SCRIP does not is silent and self-concealing, because the next session orients off the FINDING and inherits a tree state that never existed.
- **BLOCK-CANONICAL LAW**: registers are a cache valid only inside generated code; every crossing writeback/loads. A C function reading a claimed register is reading garbage BY CONTRACT.
- **RETURN-BEFORE-RELOAD**: RAX:RDX capture precedes global reload at every RC-4 site — encoder-owned, never template-owned.
- **NEVER VENEER A GENERATED TARGET**: PAT$/proc/port-label calls stay direct; veneering one deadlocks the cache semantics (generated code expects live registers). Registry is the ONE authority; an unclassified target is a BUILD ERROR, not a default.
