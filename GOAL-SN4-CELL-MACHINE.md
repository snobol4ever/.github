## MANUAL FACTS (embedded — the SPITBOL v3.7 PDF may be absent; these extracts are the normative anchors)
- **Ch.18 p.204 algorithm**: (1) cursor=0; (2) point at first element; (3) if current element has an alternative, PUSH {alternative, cursor} on the stack; (4) apply element; success → advance cursor, go 5; fail → go 6; (5) subsequent? point at it, go 3; none → WHOLE MATCH SUCCEEDS; (6) POP stack → {alternative, cursor}, go 3; stack empty: &ANCHOR≠0 → match fails; &ANCHOR=0 → start+1, go 2 if subject remains. The choice cell {resume, δ} IS step-3's entry.
- **ARB** (p.207): implicit alternatives LEN(0)|LEN(1)|…; fails only when extension would exceed subject. **BAL**: shortest nonnull paren-balanced, same implicit-extension shape.
- **ARBNO** (p.121): behaves as ('' | P | P P | …), shy, null first, extends one instance per retry; a null-matching instance stops further extension (else infinite regress).
- **Recursion requires `*`** (p.122): unevaluated operator makes self/forward reference possible; eager construction cannot self-name. Stack overflow on deep recursion is SPITBOL's own documented contract (p.123, -s to grow) — we inherit it.
- **Fullscan only** (p.123-124): exhaustive, no heuristics, deferred expressions never assumed nonnull.
- **ABORT** (p.124): fails the ENTIRE match immediately — including suppressing unanchored retry (the '-1B-A-' example fails outright). **FAIL**: backtrack now. **FENCE** (p.125): matches null forward; backing up through it fails the match; first-position FENCE anchors regardless of &ANCHOR. **FENCE(P)** (p.127): alternatives inside P invisible when backing up. **SUCCEED** (p.126): always matches null; reverses a backup (oscillator; the SUCCEED…FAIL loop idiom with @N).
- **`$` immediate** (p.87): assigns WHENEVER the subpattern matches, even if the whole match ultimately fails — write-through, never undone. **`.` conditional**: only on whole-match success, only for subpatterns on the final successful thread. **`@`**: immediate cursor assign.
- **&ANCHOR is a runtime keyword** — test it at runtime in the base-cell resume; no static classifier.
