## 2. The grammar, `bootstrap/parser_snobol4.sc` — zero functions, Shift and Reduce only, the tree in written order

The C parser is the one brought to the grammar's tree where they differed (the gotos); the grammar mirrors the C lexer where the difference is lexical (case folding, 8-bit bytes, continuation lines) and refuses what SPITBOL refuses. Every helper function the grammar carried (`sn_upr`, `SnoCall`, `ParseOne`, and the three I had written during the day) is gone: the file defines no function.

1. **Gotos stand in written order.** `:F(BAD2)S(OK2)` is F then S in the statement (14 files differed). The C's `sno4_stmt_commit_go` kept S before F whichever was written; it now records `goto_f_first` (the four F-first rules of `snobol4.y`) and `src/driver/stmt_ast.c` emits the children in that order. `lower_snobol4.c` reads the gotos by kind (`sgoto(s, TT_GOTO_S)`), never by position, so the runtime tree is unchanged in meaning.
2. **A replacement needs a subject.** `OUTPUT = ''` written at column 1 is the label `OUTPUT` followed by `= ''`: SPITBOL says *ERROR 221 missing operand*, the C says syntax error, the grammar accepted it and built a statement with no subject (6 smoke files, all of the `tests/snobol4/smoke_*` shape). The statement's replacement alternative now sits inside the subject's FENCE.
3. **A continuation line after a `;`-ended statement is error 214** in SPITBOL and the C lexer (diag2.sno line 232, and the probe `X = 1 ;` / `.  OUTPUT = 2`). The `;` terminator is guarded by a lookahead from the cursor — `@sq *(~(Src ? (TAB(sq) (SPAN(' ' CHAR(9)) | epsilon) CHAR(10) ANY('+.'))))` — that leaves the blanks for the next statement (eating them made the next statement's first word a label: 40 files of the `stmt ; stmt` shape refused until that was seen). The first cut used `ABORT` here and met the runtime defect of § 5 (b).
4. **A program without END is refused** by SPITBOL (*No END statement found*) and the C (*missing END statement*); the grammar's `| epsilon` fallback after the END statement is gone.
5. **END in any case.** SPITBOL ends the program at `end`, `End`, `eNd` and takes `:(end)` to it (probes); the C required `END` and reported *missing END statement* on `end` (8bit2.sno, p_lowend). Cured in the C at the three sites (`snobol4.l` T_END and the label token, `snobol4.y` `is_end`) with `strcasecmp`; the grammar's END statement is `ANY('Ee') ANY('Nn') ANY('Dd')` and keeps the text as written.
6. **`-CASE` folding as `snobol4.l` does it** (case1.sno): a `-CASE n` line is honoured when folding is already on or the line is spelled `-CASE` exactly; the digits after the blanks turn folding on when nonzero, anything else off; identifiers, labels, keywords, function names and goto targets fold to upper case, strings never. The grammar captures the first significant digit twice — `$ SnCaseNow` at scan time for the next control line's guard, `. SnCase` at replay time for the Shifts (the deferred assignments replay in source order, measured: a failed alternative's `. *P()` never fires, § 5 (c)) — and folds with `REPLACE(thx, SnLT[SnCase], SnUT[SnCase])`, two tables keyed by the digit (`''` maps to an identity pair, because `REPLACE` with null sets is error 171).
7. **8-bit bytes are identifier characters** to the C lexer (`ALPHA [A-Za-z\x80-\xFF]`; SPITBOL refuses them, 8bit2.sno is the one file): the grammar's `Id` takes `SUBSTR(&ALPHABET, 129, 128)`. The C's goto-state identifier rule was `[A-Za-z][A-Za-z0-9_.]*` and silently dropped the byte (`:(étude)` became `"tude"`): cured to `{ALPHA}{IDCONT}*`, consistent with its own body lexer.
8. **Continuation lines repeat** (`W ({WS}|{CONT})+`, `CONT \n[+.][ \t]*`): a bare `+` line among a run of continuations (rc.sno) ended the statement in the grammar; `Cont` is now a tail loop.
9. **An out-of-range real literal is refused** (SPITBOL *ERRONEOUS REAL NUMBER*, the C *invalid numeric item*): `((*Real) $ rtx *DIFFER(CONVERT(rtx, 'REAL')))` fails the alternative and the parse.
10. **A duplicate label is refused** (the C: *duplicate label*, SPITBOL too): the label is marked in a per-file table at scan time, `$ ltx *IDENT(SnLblT[ltx]) *DIFFER((SnLblT[ltx] = 1))`.
11. **The call node** (`SnoCall` was a function): the name's kind and value are chosen at scan time by the table test on the folded name and pushed value-under-kind on the value stack; the one `Reduce(PopVal(), nTop(), PopVal())` pops the kind first (arguments evaluate left to right, measured by the reading).
12. **The driver is inline** (no `ParseOne`): one `while` over stdin or the `PARSER_FILES` list.

- **(b) a selection `(a, b)` inside a deferred call in the compiled grammar** — `. *Shift('TT_VAR', (NE(SnCase, 0) REPLACE(thx, &LCASE, &UCASE), thx))` — jumps to address 0 on every input (`X = 1` included) in the mode-4 grammar, while the eight-line probe `'ab' ?
