**Run one program.** Frontend is chosen by extension (`.sno .sc .icn .pl .reb .raku .pas`, polyglot `.scrip`). `./scrip prog.sno` compiles and runs in-process (mode 3, `--run`); `./scrip --compile -o prog.s prog.sno` emits standalone x86-64 assembly (mode 4), linked with `gcc prog.s -L out -lscrip_rt -lm -Wl,-rpath,out`. Program arguments go after `--`. Introspection: `--dump-ast | --dump-ir | --dump-bb | --dump-zeta`. Use `timeout 8s` for smoke runs and `timeout 30s` for corpus runners; put `< /dev/null` on compile steps only, never on a run fed by a pipe or file.
