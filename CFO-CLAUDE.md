A program that dies at its cap is a ROW, read in the order the exhaustion message names -- a corrupted length, a missing safe point between two allocations, a live set that truly exceeds the cap -- and never a reason to raise the cap (clause 6). Every run's report carries `capped= grew= cap_kb=` beside `arena_kb=`, and `grew>0` disqualifies the point as evidence of the arena it names (clause 4).
