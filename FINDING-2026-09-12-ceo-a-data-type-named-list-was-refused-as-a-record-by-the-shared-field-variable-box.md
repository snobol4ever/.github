**Cause.** `rt_list_view` (pattern_match.c:23) identifies an Icon list by its layout and `gen_type` tag; the CEO-644 guard used `!strcmp(type->name, "list")` instead, so any DATA type a SNOBOL4 program names `list` read as a non-record.
