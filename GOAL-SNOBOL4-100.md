## ⭐⭐⭐⭐ BENCHMARK-PROPER — TIMED LOOPS BESIDE ITERATION LOOPS (Lon 2026-08-19 in-chat, verbatim in substance: *"get benchmarks working as TIMED loops versus ITERATION loops … industry standard technique of time limiting versus count limiting"* — the 3rd concurrent GOAL-SNOBOL4-100 session)
**THE MODEL:** every benchmark splits into KERNEL (the work, an `-INCLUDE`-able body) + two thin DRIVERS: the **iteration driver** (count-limited, fixed N — DETERMINISTIC output, stays a correctness row and the cross-engine comparability anchor) and the **timed driver** (industry shape: WARMUP window, then run the kernel until `TIME() - t0 >= MEASURE_MS`, count completed iterations, report THROUGHPUT `ips:` — iterations/second). Timing lines are NEVER correctness: the scorecard's `norm=ms` precedent extends to `iters:`/`ips:` lines (rewritten on both sides before diff).
