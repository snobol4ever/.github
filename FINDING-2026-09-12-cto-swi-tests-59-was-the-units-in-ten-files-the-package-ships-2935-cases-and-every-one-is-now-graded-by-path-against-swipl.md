**What is special about SWI.** Nothing in the population makes it small; the tooling did. The suite is SWI's own regression suite and tests SWI the dialect (modules, dicts, `=>`, rational literals, attributed variables, tabling, threads, engines, GC, its library), not ISO. Lon's 2026-09-04 ruling stands: the baseline is ISO plus the GNU/SWI-shared core and SWI-only surface goes behind a per-dialect switch (`prolog-dialect-compat-switch-swi-and-gnu`, hq_C). Those files now sit IN the denominator as reds, which is where a not-yet-landed switch belongs.

**The rebuild.** Three tools, one population, addressed by path:
- `util_swi_cut_refs.sh` walks every `.pl` that declares `begin_tests(`, runs one swipl 9.0.4 process per (file, unit) with the oracle's own `library(plunit)`, and writes `<file>.ref` beside the source with one line per CASE read from plunit's `passed/5`, `failed/4`, `failed_assertion/7`, `blocked/4`: `PASS|FAIL|BLOCKED unit:test`, `EMPTY unit`, `UNGRADABLE unit <oracle reason>`. A `forall(Gen)` test is one case per generator instance (plunit records `@(name,Bindings)`); a macro-generated test has no `test/2` head in the source at all (the xsb suites), so THE POPULATION IS THE ORACLE'S ENUMERATION, plus the source's heads for a unit the oracle could not run. 437 units cut in under two minutes at 12 jobs: 3102 PASS, 195 FAIL, 2 BLOCKED cases; 7 EMPTY units; 5 UNGRADABLE units where swipl itself SIGABRTed (`string` twice, rc=134), SIGSEGVed (`trie`, `tabled_shortest_path`, rc=139) or ran past 60 s (`rwlocks`).
- `util_swi_match.py` grades one file: for each ref case (matched by `unit:name` and occurrence order on both sides, `@(name,…)` normalised), PASS when scrip's shim verdict agrees with the oracle's (both pass, or both fail — an agreement control counted separately), FAIL otherwise with both verdicts in the row, UNGRADED with the oracle's reason for BLOCKED/EMPTY/UNGRADABLE; it prints the identity `graded + ungraded == declared`.
- `test_prolog_swi_suite.sh` runs the population in parallel in both modes, prints `SWI_BOARD`, the AND per case (CEO-372), the ungraded histogram by reason, `PACKAGE_INVENTORY` over FILES through `lib_inventory.sh` with the package's new `UNGRADABLE.tsv` (70 non-plunit files: swipl's driver, helpers, data, library modules — CONTAINER_OR_LIBRARY), `SUITE_BOARD`, and writes the SUITES.tsv row over the CASE population. `util_swi_report.py` is deleted; `util_diagnose_prolog_swi.sh` takes a path.
