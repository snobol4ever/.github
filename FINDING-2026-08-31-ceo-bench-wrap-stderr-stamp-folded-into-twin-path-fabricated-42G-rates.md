# FINDING: bench_wrap's stderr CONTEXT stamp, folded into the twin path, fabricated 42G iters/s "measurements" (2026-08-31, ceo)

**CLAIM.** Since SCRIP ffe0c5a1 (row bench-wrap-sysperf-stamp) `bench_wrap.sh` prints a `stamp: CONTEXT load1=... scrip_procs=...` line to **stderr** by design. `bench_snobol4_fixed_iter.sh:117` captured the twin path with `2>&1`, folding that stamp INTO the path variable. Every engine then ran a nonexistent file, and the harness divided N by the ~2ms error exit: the printed table read **sbl 42.86G iters/s, m3 29.03G** for arith_loop — SPITBOL "doing" 43 billion iterations per second, with `check=BUILD-ERR` only on the m4 column (whose arm alone noticed the missing file, because a missing .s is checked and a nonzero run rc was not).

**CONSEQUENCE MEASURED.** bench_triangulate_snobol4.sh printed an all-CHECK-FAIL board (TSV 20260831T001513Z, zero AGREE) — the m4 BUILD-ERR is the ONLY reason the fake sbl/m3 rates never reached a publishable AGREE row.

**TWO CURES (SCRIP, same commit).** (1) The caller captures bench_wrap stderr to a file, never into the path (`test_bench_snobol4_timed.sh` was already immune — it overwrites the capture with the `-o` path at :146, which is why angle 1 kept working). (2) `run1` now REFUSES to rate a run that produced no `check:` line (`NO-CHECK-OUTPUT`) — a twin that ran always prints one, so its absence means the program never executed, and rating N against that exit manufactures impossible rates.

**VERIFIED.** Re-run after the cure (TSV 20260831T002114Z): angle 2 measures again; 6 of 19 kernels fully AGREE on a loaded box (op_dispatch 3.40x, string_concat 2.89x, fibonacci 1.74x, pattern_bt 1.44x, eval_fixed 0.88x, table_variety 0.62x — m3 vs sbl, angle-1 rates), the rest DISAGREE with the load signature (angle-2 uniformly ~1.1-1.7x above angle-1; 7 concurrent scrip procs stamped). The verified six are published in README; the thirteen are withheld as unverified, per the harness's own gate.

**CLASS.** "Non-empty is not alive" + instrument-blindness: an arm that checks only its own build artifact (m4) beside arms that check nothing (sbl/m3) makes the honest column look like the broken one. A rate without a survivorship check is a claim about the error path.
