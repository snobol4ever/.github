## 2. THE RULINGS (CEO-1888; each is one step's law, R1-R12 in step order; the one-line forms are in STEPS.tsv)

- **R1 -- EVERY NAME IS DECLARED BY THE LOWERER; THE EMITTER REFUSES NOTHING A ROAST FILE READS.** The `[SMX]` refusal is a gate at the wrong stage: a name the lowerer did not resolve reaches the emitter as a read with no writer. The lowerer declares every name a program introduces -- a sigilless `my \a`, a `constant`, a `::T` capture used as a type or a value, a pod block, a compile-time `$?` variable, an `our`, an enum member, a package-qualified name -- and an unresolved name is a lowering error that names the file's line (Rakudo's `Variable '$x' is not declared`); the 20 `rhs shape with no native arm` and the 5 excised nodes are lowerings. The refusal at scrip.c:638 stays as the emitter's self-check and fires on no roast file.
- **R2 -- POD IS DATA.** `=pod` is the biggest single name (19 files) because a pod block is lowered as a variable. The parser keeps every pod block as a tree node and the lowerer builds `$=pod` as an array of prelude objects (Pod::Block::Named, ::Para, ::Code, ::Table, ::Comment, ::Declarator, Pod::Heading, Pod::Item, Pod::Defn, Pod::FormattingCode; `.contents`, `.name`, `.config`, `.level`) and `.WHY` on a declared symbol from `#|` and `#=` comments; Rakudo's structure is the ref (`=head1 Title` is a Pod::Heading whose contents is one Pod::Block::Para; a paragraph with no blank line joins the heading).
- **R3 -- A CONTAINER EXISTS WHERE THE PROGRAM ASKS FOR ONE.** A variable's slot holds its value, as today (THE LIFETIME RULE: a lexical lives for its scope's frame). `:=` between lexicals of one scope or an enclosing one is a compile-time alias of the slot; a run-time binding (an array element, a hash value, a conditional bind) stores a REF descriptor to a heap Scalar cell dereferenced at every use by a tag test; an `is rw` parameter receives the address of the caller's slot for the call's lifetime (a stack word of the caller's frame, never escaping); `VAR(x)` and `.VAR` answer a Scalar object over the slot or the cell (`.^name` Scalar, `.name`, `.of`); a bound literal is immutable and an assignment to it dies X::Assignment::RO. The meta calls `VAR WHAT HOW WHO WHICH WHERE` exist as functions (hq_raku's item 1 of its rank-1 row asked this seat).
- **R4 -- A ROLE IS A TEMPLATE; COMPOSITION INSTANTIATES IT PER CLASS.** hq_raku's measured divergence: Rakudo gives each composing class its own copy of a role-body lexical (1,2,1) and SCRIP keeps one per role (1,2,3). The cure is in the lowerer's composition: `does R` copies R's hoisted body (its `my` lexicals, methods, attributes, required-method list) into the composing class once per class; a parametric role instantiates once per (class, argument tuple) (`Cnt2[Int]` composed by C and by E are two copies: 1,2,1,1); a run-time mixin (`$v but R`, `$v does R`) composes an anonymous class per mixin site over the value's type, retags the value to it, and owns its own copy of R's body; conflicts and required methods are the composing class's errors at lowering. Nothing per role is shared but the template.
- **R5 -- THE SEQ MACHINE IS THE GENERATOR ROAD, COMPLETED.** The gather and `...` boxes landed (ARCH-RAKU-BOXES step 2, DONE); what is left is the Seq as a VALUE: `.iterator`, `pull-one`, `push-exactly` are the generator's beta driven by a consumer box; `is-lazy` is a fact of the Seq (an infinite range or a `lazy` mark is lazy, a finite gather is not); a Seq that ESCAPES its expression -- assigned to a scalar, returned from a sub, stored in an attribute -- becomes a co-expression with its own stack (the ESCAPE BOUNDARY, CEO-1619; Icon's `create`) resumed by `pull-one`; lazy `map`/`grep`/`first`/`head`/`tail` chains are generator boxes over the source generator with no array staging. No cap, no eager array (the `rk_desugar_gather` shape of 10-10 is history).
- **R6 -- A REGEX IS A PATTERN GRAPH; rx.c RETIRES.** ARCH-RAKU-BOXES step 3 as written, with the decisions a builder needs: the regex tree `rk_regex.c` already builds is lowered at compile time into the four-port boxes of its kinds (literal, class, alternation ordered by longest token, quantifier with backtracking, positional and named capture building `$/` as a Match tree, anchor, lookaround, named rule call with recursion, `:ratchet` for token and rule, sigspace, `<~~>`, a closure); a grammar's rules are procedures whose alpha enters the pattern at the cursor and whose gamma returns the Match, actions run at a rule's gamma, `s///`, `.subst`, `m:g`, `.match` are drivers over the same boxes; the pattern boxes are SNOBOL4's where the kind is the same (the match plane's leaves, not a second engine). `rx.c`, `re_match`, `re_matchx`, `grammar_parse_core` have no caller and are deleted; backtracking boxes, never an NFA or DFA (CEO-1602).
- **R7 -- AN EXCEPTION UNWINDS BY THE FRAME WALK.** `die` finds its handler by ARCH-GC section 13's chain (return PC, site table, link word) -- the nearest frame whose shape carries a CATCH or CONTROL block -- running each left frame's LEAVE and UNDO phasers on the way, restores rsp and rbp to that frame and enters the handler's alpha with `$!` bound; a `when` in CATCH that matches handles, an unmatched exception rethrows from there; `.resume` returns to the throw site for a resumable exception (warn, CX::Warn); `fail` returns a Failure (a value carrying the exception, false and undefined until handled, thrown when used or sunk, fatal under `use fatal`); `return`, `last`, `next`, `redo` across block boundaries and labels are control exceptions on the same walk; ENTER, LEAVE, KEEP, UNDO, FIRST, NEXT, LAST, PRE, POST are blocks the frame's SHAPE names (static data, CEO-1542: never a per-activation table); the typed exceptions X::AdHoc, X::Multi::NoMatch, X::TypeCheck::Binding, X::Assignment::RO, X::Method::NotFound are prelude classes printing Rakudo's messages. No second stack, no handler table a global holds.
- **R8 -- DISPATCH IS RESOLVED OR TABLED, NEVER SEARCHED BY NAME.** ARCH-RAKU-BOXES step 4: a multi's candidates are sorted at lowering by type narrowness and bound at the call by a generated dispatcher (arity, type, `where`, named, optional, slurpy, coercion `Int()`), `proto` with `{*}` wrapping the chosen candidate, X::Multi::NoMatch and X::TypeCheck::Binding on failure; a method call on a receiver of known type resolves at lowering; an unknown receiver dispatches through a per-type table (name to address) the lowerer emits, which `.can`, `.^name`, `.^methods` read; `rt_str_method`, `rk_list_more_methods`, `rt_multi_meth_dispatch`, `invoke_method_proc` have no caller.
- **R9 -- SMARTMATCH, JUNCTIONS AND METAOPERATORS ARE BOXES.** ARCH-RAKU-BOXES step 5: `~~` lowers by the right operand's kind where the lowerer knows it (type, regex, code, range, junction, literal, list) and through a kind switch box otherwise, `given`/`when` the same; a junction at a relop or a sub argument autothreads as the box's own alternation over the eigenstates and collapses at a boolean context, `junction_collapse` retired; `[+]`, `>>.`, `Z`, `X`, `R`, `!`, `=` and the hyper forms lower to loops over boxes.
- **R10 -- Test IS A RAKU MODULE SCRIP COMPILES.** Rakudo's `lib/Test.rakumod` (953 lines, Artistic 2.0, vendored into the prelude) replaces the C arms: every roast file's `plan`, `ok`, `is`, `throws-like`, `dies-ok`, `subtest`, `is-deeply`, `done-testing` is SCRIP's own compiled code, so the 590 files using throws-like or dies-ok read their real first failure and `You planned N tests, but ran 0` stops hiding the cause; `__rk_test_*` is deleted. ## 4. WHAT A BUILDER MUST NOT DO

No C function enters a box (CEO-1576): a dispatcher, a handler search, a Seq's consumer are boxes, and a C leaf returns a value or an address. No global, static or arena word holds a handler chain, a phaser list, a generator's state or a scan of frames: the frame's SHAPE names its blocks (CEO-1542) and the chain walk finds the frame. No eager array behind a lazy construct and no cap on a Seq. No `strcmp` chain on a name at run time where the lowerer could resolve it or table it. No second regex engine beside the pattern boxes, and no NFA or DFA (CEO-1602). No per-role shared state: composition copies. No new `g_` member without Lon's banner grant; the thread runtime's cells are CEO-1764's struct. A Roast file the oracle refuses is EXCLUDED, never fudged; a file Rakudo answers stays in the denominator. The RakDemo's ref is `raku --target=parse`'s own dump, never a hand-written tree.

## 6. Rulings on step 1's order and the cfo's review of R3, R5 and R7 (the cto, 2026-10-29 11:0x CDT; hq_raku's nine landings SCRIP 42e2f0152..dad0acc4f, the residue 128 of 237; the cfo's telegram of 10-28 21:3x)

AFTER: landing it first would turn 128 `[SMX]` refusals into 128 lowering errors and move the probe without moving a program. - **R3 (1): A LEXICAL CAPTURED BY A BLOCK THAT ESCAPES IS HEAP-HOMED FROM ITS DECLARATION.** THE ESCAPE TEST is a lowerer fact on the block: a block that reads or writes an outer lexical and is used as a VALUE (returned, assigned, passed as an argument, stored, bound to a name, the body of `gather`, `start`, `map` with a lazy consumer) escapes; a block that is the body of a control construct executed in place (if, for, while, a bare statement block, `do`) does not. Every outer lexical such a block captures is a heap Scalar cell (a REF in the frame slot) from its declaration, never moved at the point of escape (a move would leave the block's earlier alias pointing at the frame). Witness rr03's `sub make-counter { my $c = 0; { $c++ } }` called twice with two independent counters. Conservative by construction: a block whose use the lowerer cannot classify escapes.
- **R3 (2): `is rw` OVER A NON-LEXICAL PASSES A REF, NEVER A RAW ADDRESS.** `f(@a[3])` and `f(%h<k>)` with `is rw` pass a REF descriptor whose value word is the ELEMENT's cell address inside the heap block (an interior pointer; the visitor is the DT_S arm's `gc_blk_of` walk, as ARCH-PASCAL-REDESIGN 8.8 rules for the pointer kind), relocated with the block during the call; over a lexical the value word is the caller's slot address, outside the arena, which the same visitor ignores. ONE kind, one visitor, the tag says REF, so no frame map describes a bare stack address: the callee's parameter slot holds a DESCR of kind REF and nothing raw. Dereference at every use by the tag test (R3 as written).
- **R5 (3) and (4): AN ESCAPING Seq's STACK IS THE ATTRIBUTE ROW's, AND ESCAPE IS CONSERVATIVE.** The co-expression an escaping Seq becomes takes its stack size from the program's attribute row (`stack_kb`, CEO-1353; Icon's co-expressions read COEXPSIZE the same way), and the collector walks a live co-expression's mapped frames as it walks Icon's (ARCH-GC section 13's chain from the co-expression's saved link). Any Seq value not consumed inside its own expression escapes: assigned, returned, stored, passed to a routine the lowerer does not know to be eager.
- **R7 (5): A die INSIDE A C RUNTIME CALL RETURNS TO EMITTED CODE FIRST.** CEO-1576: no C function enters a box, so the C leaf records the exception in the thread's pending word and returns its failure code; the emitted call site tests it (the same place the allocating poll sits) and starts the walk FROM EMITTED CODE. The walk never starts in a C frame and never steps over one: no C frame is ever between two emitted frames it walks, because C never calls back into a box.
- **R7 (6): THE HANDLER's ENTRY DEPTH IS A SHAPE FACT.** The frame's SHAPE carries, per CATCH or CONTROL site, the depth rsp is restored to (`rbp - k`, the planner's fact for the handler's alpha entry, as a column of the shape's static data), never a recomputation and never a saved rsp in the frame.
- **R7 (7): THE WALK HAS TWO MODES, FIND THEN UNWIND.** FIND locates the handler by the chain and runs the CATCH or CONTROL block ON TOP of the throwing frames (a call from the throw site with every frame intact, which is how Rakudo runs it); if the handler resumes (`.resume`, a warn's default, a `when` that handles a CX::Warn) execution returns to the throw site with nothing unwound; if it leaves without resuming, UNWIND runs each left frame's LEAVE and UNDO phasers, restores rsp and rbp to the handler's frame by (6), and continues at the handler's frame. An unmatched exception rethrows from the handler's frame by the same two modes.
- **R7 (8): last, next AND redo TO A TARGET IN THE SAME FRAME ARE DIRECT JUMPS.** The lowerer resolves them when the loop is in the same graph (the common case, SCRIP 30a76fc06's labelled forms included); the frame walk is kept for a control exception that crosses a sub boundary (a `last` inside a block called as a sub, a `return` from inside a map closure), so a hot loop pays no walk per iteration.

## 7. THE CONSTRUCT LADDER IS THE METHOD AND THE PROBE IS THE MEASURE: where a one-feature rung goes, who owns the feature order, which of step 1's landings are constructs and which witnesses split (the cto, 2026-10-29 12:0x CDT; Lon's direction to hq_raku of 10-29, relayed by its telegram; the ten landings SCRIP 42e2f0152..497cd01a0, 979976db1; corpus 393737a23..282c300f3)
