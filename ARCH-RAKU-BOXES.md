# ARCH-RAKU-BOXES.md — Raku's logic is in C today; the box design that replaces it

**Minted 2026-10-10 10:4x CDT by the ceo on Lon's word (in-chat to the ceo, verbatim: *"Let's begin scrutinizing Raku's design. I want to ensure we are using Byrd Boxes properly and not coding logic inside C functions."*; CEO-1600). Measured on SCRIP `59d1dae63` by a read-only survey the ceo spot-checked in the source (the five claims below marked ✓). Function sizes are from a brace-counting pass and are close, not exact.**

## 0. The verdict

**No.** Calls, method dispatch wiring, junction values and the grammar body shapes are boxes; interpolation is boxes. But the four things that make Raku Raku — generators (`gather`/`take`, the sequence operator `...`, lazy lists), regex and grammars, method and multi dispatch, and smartmatch — are implemented as C logic in `src/runtime/by_name_dispatch.c` and `src/runtime/rx.c`, and the C runtime still tries to call user code at 21 sites. About **9,300 lines of Raku-only C** carry program logic (plus 1,681 lines of tables), against a lowerer of 4,349 lines that emits 24 IR kinds reaching 20 box templates — Icon's lowerer emits 72 kinds reaching about 54 templates. The one live generator box Raku emits is `bb_to` (a counted loop).

## 2. C calling user code — 21 sites, 0 open roads among them

Raku's C has no direct `rt_c2bb_bomb`; the 21 sites below reach the named bomb `rt_call_proc_descr` (rc 139) because they pass no request `rq` (12 direct sites in `by_name_dispatch.c` ✓; the rest through `invoke_method_proc`): **block calls inside C loops (11)** — `s///` with code :1285, the sequence operator :2628/:2647, `unique :as`/`produce` :2799/:2823, the old `subtest` arm :10962, the sort comparator :12061, `reduce` :12101, smartmatch against a code block :12228, `map`/`grep` fallback :12352, `first` :12397; **`invoke_method_proc` without `rq` (6)** — grammar actions :9105, `callsame`/`nextsame` :12711, :13310, FALLBACK :13373, :13391, :14536; **direct (3)** — TWEAK :3910, BUILD :3951, EVAL :12671; and `arithmetic.c:101` `rt_binop_overload` calling `__multi_call` from C, reached from `bb_binop_relop_val.cpp:141`. hq_raku's `0f084663d` (the block road) ADDED emitted paths and deleted none of these: the count is the same on both trees. The seven OPEN ROADS that do return an address (`rk_method_open` :3833, :4105, `__multi_call` :11077, `__blk_invoke` :11101, `__rk_named_call` :11707, `obj_new` :12962, `meth_call` :13282) are gated by `rt_builtin_tail_may_open` (:13774) and entered from `bb_call.cpp:243-247` and `bb_call_fn.cpp:78` — the CEO-1576 shape, which is what every one of the 21 must become.

## 3. How `lower_raku.c` lowers each construct today

- **Loops and list methods:** `for` over a range is `IR_TO` (`bb_to`, :1469); over a list an `IR_TO` index loop with `__rk_arr_at` leaves; `.map/.grep/.first/.reduce/.sort` with a block go through `rk_lower_iter_meth` (:668) as an `IR_TO` loop calling the block as a compiled call; a two-parameter sort comparator becomes a merge sort written as a Raku sub (:3733/:3561); any other shape falls back to `IR_CALL meth_call` and the C loops of § 2.
- **`gather`/`take`:** `rk_desugar_gather` (:3502 ✓) and `rk_take_rewrite` (:3483 ✓) turn them into an EAGER ARRAY plus `push`; a bare `TT_GATHER`/`TT_SUSPEND` is excised (:1587, :1813). No generator box: an infinite `gather` never returns.
- **`...`:** the parser emits `__rk_seq` (`rk_tree.c:1610`) → `rk_sequence` in C, eager, capped.
- **Junctions:** `IR_CALL __rk_jct_*` builds a value (:1344); collapse happens in C from the relop boxes.
- **Regex and grammars:** `m//` becomes `IR_CALL re_match`/`re_matchx` (:1565-1584 ✓) into `rx.c`; `Grammar.parse` → `grammar_parse_core` (:936) in C. `IR_GLIT`/`IR_GCC`/`IR_GALT` grammar boxes are built (:2408, :2457) and have emit arms (`emit.cpp:1604-1606`); the survey reads them as never registered at run time — hq_raku measures that first.
- **Methods and multis:** `IR_CALL meth_call` (:1752) and `__multi_call` (:1288, :1770), resolved in C by name; `.new` with BUILD/TWEAK a helper sub since `dba59c137` (:3676), otherwise `obj_new` (:1795).
- **`~~`:** the parser emits `__rk_smartmatch` (`rk_tree.c:1558`), handled in C (:12206).
- **Interpolation:** `TT_CAT` into `IR_BINOP` concat boxes (:809) — boxes.

**Icon beside it:** `suspend` is `IR_SUSPEND` → `bb_suspend` (`lower_icon.c:1542`) where Raku's `take` is a `push`; string scanning is `IR_SCAN_ENTER`/`IR_SCAN` and `tab/move/upto/find` are `IR_SCAN_*` boxes (:859-927) where Raku's `m//` is a C call into an interpreter; Icon generators are `IR_ITERATE`, `IR_PROC_GEN`/`IR_CALL_BUILTIN_GEN`, `IR_LIMIT`, `IR_REPALT`, with `every` driven by the generator's β (:2807) where Raku's `...` is `rk_sequence` and `map`/`grep` are counted loops.

## 4. The design — what replaces it, in this order

The law stands as written (RULES.md § LOGIC LIVES IN EMITTED BOXES, NOT IN C; § ERADICATE C→BB→C→BB; CEO-1576): the C runtime is a LEAF that returns a value or an address; every construct that proceeds, recedes, succeeds and concedes is a four-port box wired at compile time. Raku is the fourth syntax over the one machine, and its boxes are the ones SNOBOL4, Icon and Prolog already have.

1. **No C site calls user code (rank 1, the current reds).** Each of the 21 sites becomes the CEO-1576 shape: the C leaf returns the callee's address (or the lowerer emits the loop so no C loop exists — `sort`, `reduce`, `first`, `map`/`grep` fallbacks become `IR_TO`/generator loops that call the block as a compiled call, the way `rk_lower_iter_meth` already does for the shapes it covers), and the box that called it makes the jump. `s///` with code, grammar actions, `callsame`, FALLBACK, `unique :as`, `produce`, EVAL and the sequence blocks are the list; BUILD/TWEAK are cured (`dba59c137`). The census `rt_call_proc_descr`-without-`rq` reads 0 outside `rt_call_proc_descr` itself.
2. **Generators are generator boxes (rank 2).** `gather` is a suspendable procedure shape — Icon's `bb_suspend` road: `take` is γ-SUSPEND, the consumer's β resumes it — lazy by construction, so an infinite `gather` with `.head(3)` answers; `...` is a generator box over the same road (the generator block called per step through the open road; the end condition the box's ω), with NO CAP; `map`/`grep`/`first` over a lazy source drive the source's β; `is-lazy` reads the shape, not `False`. The eager array desugar and `rk_sequence` retire; the 100000 cap goes with them (NO FIXED LIMITS).
3. **Regex and grammars are emitted boxes (rank 2).** A Raku regex is a pattern graph exactly as a SNOBOL4 pattern is — literal, class, alternation, quantifier, capture, anchor, lookaround, named rule call — and every node compiles to the four-port box of its kind at compile time (the `bb_*` pattern family SNOBOL4 and Icon's scanning already use, plus the Unicode class leaves); `m//`, `s///`, `~~` against a regex, `token`/`rule`/`regex` and `Grammar.parse` are wirings of those boxes, actions a call at a capture's γ. `rx.c`'s runtime regex parser and `mnode` retire; a regex built at run time from a string is compiled by the same lowerer road a stored SNOBOL4 pattern takes. The dead `IR_GLIT/GCC/GALT` arms are measured first and either become the live road or are deleted.
4. **Dispatch is resolved, not searched (rank 3, with the performance phase).** A method call on a value whose type the lowerer knows resolves at compile time to the leaf or sub; an unknown receiver dispatches through a per-type table the lowerer emits (name → address), never a `strcmp` chain; `rt_str_method`'s 101 compares, `rk_list_more_methods`, `rk_io_path_method` and the by-name `IR_CALL` resolution (`try_call_builtin_by_name_bl_s_rq`) are the population. Multi-dispatch candidate selection is emitted per call site from the declared signatures.
5. **Smartmatch and junction collapse are boxes** — `~~` lowers by the right operand's kind (type, regex, code, value) to the box of that kind; junction collapse at a relop is the relop box's own alternation over the junction's eigenstates, with the C `junction_collapse` retiring. Rides with 3 and 4.

LARGE CHUNKS applies to each step: the scheme built whole, rolled out to one construct with its smoke (RakRungs entries of that feature through the area smoke), then everywhere the scheme governs in hq_raku's lane, then Lon's ultracode. The DONE-WHEN of each row is a fixed witness equal to rakudo in both modes plus the census that the retired C road is gone — never a count alone.
