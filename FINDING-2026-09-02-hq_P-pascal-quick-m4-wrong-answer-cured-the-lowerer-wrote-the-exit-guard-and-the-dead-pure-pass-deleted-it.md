## 2. The link — the lowerer wrote the guard, the optimizer deleted it

`lower_pascal_proc` (`src/lower/lower_pascal.c:661-663`) already builds the exit so that no raw value can reach it:
```
if (is_func) { ret = IR_RETURN(succ); rv = IR_VAR(fname) → ret; operand_push(ret, rv); top = rv; }
else         { safe = IR_LIT_INTEGER 0 → succ;                                          top = safe; }
body_gamma = top;
```
A function's body flows into RETURN(result variable); a procedure's body flows into a literal 0 whose γ is IR_SUCCEED — `safe` by name and by intent: a tagged value in `rax:rdx` at the exit. **`--dump-ir` shows it in place** (`qsort`: node 70 `BINOP_TEST binop=5` ω → node 74 `LIT_INTEGER 0` γ → node 75 `SUCCEED`). **And `src/optimizer/dead_pure.c:19` rewrites every pure literal that no node names as an operand into `IR_SUCCEED`** — the guard names nothing and nothing names it, so it is deleted, the relop's ω is retargeted straight onto the exit, and the `.s` shows exactly what seat09 read: `qsort_res:` with no load, `qsort_γ: mov rdi, rax`. ## 3. The cure — one statement, Pascal-local, the function shape

