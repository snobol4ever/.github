## Debugging order — THE MONITOR BRACKET, then ASM-DIFF-FIRST

**Step zero for every suite red is the IPC sync-step monitor** (RULES.md § THE MONITOR BRACKET, CEO-1217/1270): the bug lies between the **last event both sides agree on** and the **first they diverge on**; a gdb step or `--trace` across that gap walks onto it.

```bash
bash ../harness/scripts/monitor_run.sh prog.pl --oracle            # SCRIP m3 vs gpx (GNU Prolog fork); MONITOR_PL_ORACLE=swipl uses swx
bash ../harness/scripts/monitor_run.sh prog.pl                     # --modes: m3 vs m4, when only one mode is red
bash ../harness/scripts/monitor_run.sh prog.pl --trace             # the m3 event trace alone
#   --input FILE feeds stdin (default: <base>.input beside the source); MONITOR_LAST_AGREE_TRAIL=N widens the agree trail
```

Read its code header for the verdicts: rc 0 prints **`AGREE`** only at `UNGRADED=0` — an `UNGRADED=n` line means *n* values were never compared, not that they matched; rc 1 diverged; rc 2 could not measure (no compile, no oracle bridge, or **not monitor-safe** — it checks that tracing did not change the program's output, and refuses rather than grade a different program). Each cure's commit names its bracket (program, step, first diverging event) or why no bracket was possible. **Only after that** does ASM-DIFF-FIRST (RULES.md § ASM-DIFF-FIRST BUG-FINDING) apply:

1. **Mint the smallest repro** — ablate toward a minimal witness. A passing sibling with one ingredient removed is worth more than a trace.
2. **Diff the emitted `.s`** between passing sibling and failing witness (`--compile`, no gdb). An instruction byte-identical across both is exonerated. ⛔ **SCOPED TO ONE MODE, since MODES MAY DIVERGE** — the exoneration premise holds only *within* a mode. A cross-mode difference is legal divergence, not evidence: an instrument comparing **answers** survives the ruling; one comparing **emissions** must name its mode.
3. **Only then gdb** — breakpoint at the implicated site with a hit/spin count (`ignore <bp> <N-1>` or `condition`). Hardware watchpoints are unreliable here, not absent — try, then fall back.

⛔ **`CSN_NO_SEGV_HANDLER` / `SCRIP_NO_SEGV_HANDLER` ARE NOT SCRIP'S AND NEVER WERE** — they belong to the separately-cloned csnobol4 oracle. The habit began at s65 and spread by copy to 15+ roots. ⭐ **Nobody caught it because the gdb step genuinely works**: ptrace stops the inferior *before* any in-process handler runs, so backtraces are clean either way.
