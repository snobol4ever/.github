## Shared code: what a layer landing owes beyond the recipe
- Every language rides your code: all eight smokes (`test_smoke_snobol4.sh` `_icon` `_prolog` `_pascal` `_raku` `_snocone` `_rebus` `_polyglot`) before the push, and the emission-identity proof (eight programs, one per language, the same `.s` before and after) when the emitted text may move; the coo grades the identity sweep.
- A generated table follows the code it describes, regenerated in the same landing: `util_gen_gc_allocating_table.py` after any allocating runtime function, `box_cell_shapes.inc` after a new IR kind (a row in `harness/scripts/box_cell_shapes.tsv`, then `--write`), the rtx clobber table after a leaf; the freshness guard refuses a stale one.
- A red a language seat names in your layer is yours within the tick; a red you find in a language's lowering goes back by bus. The planner decides every home (never the emitter); no C function enters a box; the collector guesses nothing; a template is one return, no locals, one `x86()` call per line.
