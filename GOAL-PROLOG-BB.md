**WHAT THIS IS.** s141 measured mode-4 nrev at ~86% C-runtime / ~14% emitted leaf samples — the inverse of SNOBOL4. ### THE SINK CONTRACT (binding on every rung — violations are the bug class this ladder exists to avoid)
1. **WHOLE-ARM-OR-DEFER.** The inline path either completes an ENTIRE C-leaf arm verbatim or jumps to SLOW with **unmodified rdi=args** — never partial state into the leaf. If a rung's leaf has sequential sub-arms (SINK-2's H-then-T), PRE-CLASSIFY every sub-arm's tags BEFORE executing any bind, and defer the whole call unless all sub-arms are inline-decidable (an idempotence proof is an acceptable substitute but must be WRITTEN in the rung's FINDING).
2. **⚠ THE DT_N LESSON (s142, measured).** Marshaled variable operands arrive as `DT_N` name-ref wrappers (slen1 → `p`; slen2 → `VCELL.cellp` @+0) — that is `plw_entry`'s reason to exist. A sink that bails on tag 9 NEVER FIRES: SINK-1's first cut was +8% pure overhead; folding both DT_N chase arms into the inline deref flipped it to 1.86×. **Every rung's deref must be a faithful `plw_cell_deref_slow` (minus poison read + 4096 guard) — reuse `sink_deref` verbatim.**
3. **RUNTIME-INTERNED IDS ARE UN-BAKEABLE.** `dot_sl` (`intern(".")<<16|2`) and every functor slen are assigned at RUNTIME (the m4 GZ preamble never runs `prolog_atom_init`) — they CANNOT be mode-4 immediates. Pattern: a per-leaf exported u32 cell (`g_plw_dot_sl`-style, RIPSEAL-loaded) filled by the C leaf's existing static-init, OR a per-SITE .bss cache filled on first slow-path hit. This is a sanctioned-global question (g_pl_flags precedent) — raise it in the rung's FINDING and keep `no_new_global` gate honest.
4. **GC/FLOOR SKIP IS FOR NON-ALLOCATING ARMS ONLY.** The safepoint + unwind-floor stay in the leaf when the inline arms allocate nothing and throw nothing (SINK-1). Any ALLOCATING inline (SINK-3 carve) keeps GC in C by construction: bump `top`, compare `limit`, exhausted → SLOW (the leaf's alloc does init/grow/collect). Any THROWING arm (iso errors) → SLOW, always.
5. **ENCODER WIDTH TRAPS.** `x86("cmp",reg,imm)` is 32-BIT ALWAYS (no REX.W) — qword-vs-imm needs `"cmp64"`; TEXT would silently print 64-bit while BINARY compares 32 (medium divergence). `add`/`sub`/`imul`/loads are width-aware by register name. `[reg + d]` = qword REGDISP; `"dword ptr [reg + d]"` = 32-bit. Dual-medium global load = `x86("lea", r, "[rip + __]", (uint64_t)&sym, "sym")` (TEXT rip-relative symbol, BINARY movabs live address; symbol must be exported — verify `nm -D out/libscrip_rt.so`). No `shl` encoder — use `imul` with a constant reg, or add the encoder (R7).
6. **LAYOUT ANCHORS.** Every struct offset a template bakes in gets a `_Static_assert` beside the C twin (SINK-1's pair beside `plw_bind` is the pattern). Template and runtime move together or not at all.
7. **LABEL IDS.** Per-box namespace; `marshal_call_arg` owns `idx*2`/`idx*2+1` (≤7 for 4 args). SINK-1 owns 40–58. Allocate each rung a fresh decade (SINK-2: 60–79, SINK-3: 80–99, …) and RECORD it in the rung's FINDING.
8. **KILL SWITCH — AND PER-RUNG ISOLATION (amended s146).** `SCRIP_NO_SINK=1` at EMIT time disables the whole family. ⚠ **THE FAMILY SWITCH CANNOT MEASURE A RUNG** — it compares {all landed} vs {}, so on any bench where an earlier rung is hot the NEWEST rung harvests every prior rung's win (SINK-8 read 1.59x that way; isolated truth 1.056x). Give every rung a `SCRIP_NO_SINK<N>` nested INSIDE the family switch (default enabled, changes nothing) and A/B with THAT. **Also: a ~5% effect needed 60 runs/arm before its sign was consistent** — at 3 runs/arm one block showed OFF faster. **And OUTPUT IDENTITY IS NOT WORK IDENTITY:** a failure-driven bench printing only `done` prints it FASTER if it silently does fewer iterations; prove equal work with an independent unsunk counter. The family switch (mode-3 emit==run; mode-4 set at compile). Every rung nests inside the `dfp` branch so `SCRIP_NO_DOP`/`SCRIP_DOP_SKIP` disable it too. `SCRIP_PL_POISON_TRAP` sessions must set `SCRIP_NO_SINK` (inline arms skip poison reads).
9. **BENCH DISCIPLINE.** The NO-LCO defect caps recursion (16-wide body dies at depth 10; 4-wide ~60; even a shallow 4-wide call pyramid dies between 64 and 256 total calls — cumulative exhaustion). Benchmark with FAILURE-DRIVEN loops (trail rewinds per iteration) and A/B via TWO mode-4 binaries with the sink baked on/off at compile time (JIT-emit cost pollutes mode-3 micro numbers).

## ⛔ NO C BYRD-BOX FUNCTIONS — A BOX IS ENTERED BY JUMPING TO ITS α/β LABELS, NEVER A `(ζ, int entry)` C CALL

**There is NO such thing as a C byrd-box function. The "brokered BB" concept is ABOLISHED.** A byrd box is
EMITTED machine code. It has exactly TWO entry points, and they are **LABELS** — α (fresh entry) and β
(resume). Control reaches a box by **JUMPING to one of those labels**. A box is NEVER a C function, is NEVER
