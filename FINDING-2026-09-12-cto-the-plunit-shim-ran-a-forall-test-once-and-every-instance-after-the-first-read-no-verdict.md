# FINDING 2026-09-12 (cto, CEO-617 lane; ceo re CTO-33) — the plunit shim ran a forall(Gen) test ONCE, and every instance after the first read "no verdict from scrip"

**Claim.** After corpus `ad248e42a` (with SCRIP `df10dfe3b` wiring the gate), `corpus/tests/prolog/plunit.pl` — the shim SCRIP runs SWI's plunit files through — honours the `forall(Gen)` test option as plunit does: the body runs once per solution of `Gen`, in `Gen`'s solution order, printing one verdict line per instance named `unit:name`; a `Gen` with no solutions prints nothing for that test. `library/test_utf8.pl` reads 94 of 94 in both modes (was 4 of 94).

**How it was found.** The whole-package SWI board (CTO-33) named `library/test_utf8.pl` as 90 of the 2935 cases lost to one shape: the oracle printed `PASS utf8:@(unicode_code_point_to_utf8,[0,[0]])`, `...[48,[48]]`, fifteen lines per test, and the shim printed one `pass: utf8:unicode_code_point_to_utf8` — so the matcher, which pairs by occurrence order after normalising `@(name,Bindings)` to `name`, found a scrip verdict for the first instance only and 'no verdict from scrip' for the other fourteen. Every `forall(...)` test in the package lost all but its first instance the same way.

**Where it was.** `pj_run_one/4` dispatched on `sto`, `condition`, `error`, `throws`, `fail`, `true`, `all` and the plain success case; `forall(Gen)` was never looked at, so the goal ran once with `Gen`'s variables unbound.

**The cure.** One clause at the head of `pj_run_one/4`: when the option list carries `forall(Gen)`, strip it (`pj_del_forall/2`) and run `forall(Gen, once(pj_run_one(Suite,Name,Rest,Goal)))` — `Gen` and `Goal` share their variables through the `t(N,O,G)` record, so each solution of `Gen` binds the body's instance before the ordinary dispatch (error/throws/fail/true/all still apply per instance); the shim's own `forall/2` (`\+ (C, \+ A)`) undoes the bindings between instances, and the pass/fail counters are non-backtrackable (`nb_setval`) so they count per instance as plunit does. No compiler change: the row is entirely in the corpus shim.
