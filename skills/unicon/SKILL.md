## 1. The rulings

- **R1 the markers and the Icon fallback**: a file is a UNICON PROGRAM when its code (outside comments and strings) carries a declaration-level `class`, `package` or `import` header, or the words `thread`, `critical` or `abstract`; in a Unicon program the eight words (`class method initially import package thread critical abstract`) are reserved everywhere as unicon reserves them; a markerless file is plain Icon and its plain identifiers stay identifiers. `icn_source_is_unicon` (icon_lex.c) is the one reader; the parser sets the lexer flag `lx.unicon` from it.
- **R2 the oracle**: `unicon_bin()` in `harness/scripts/lib_oracle_flags.sh` (`$UNICON_ORACLE_BIN`, `/home/resources/unicon/bin/unicon`, never a bare name; built by `build_unicon_oracle.sh`) answers every program that carries a marker and the UniTests package whole. A markerless Icon program's oracle stays Arizona `icont`/`iconx`; the IPL, Arizona, Jcon and IcnRungs refs do not move. One oracle per package. Compile `unicon -s f.icn -o f.uni` (an output named `*.u` is taken for ucode and fails), run `./f.uni`, never `unicon -E`. A ref is run twice and identical.
- **CTO-473, a markerless program graded by the unicon oracle is Unicon because the package says so** (option a): `scrip --dialect=unicon` (scrip.c, `icon_compile_as` in icon_driver.c) forces the Unicon state exactly as a marker does and stamps the root of the parse tree (`TT_PROGRAM` `v.ival`); nothing past the driver sees a flag (CEO-1838/1840). `corpus/packages/icon/unicon_tests/CONTRACT.tsv` carries `unmarked_compile_args --dialect=unicon`; `util_build_package_suite.py` writes it into `ALL.csv` compile_args for the entries `icn_marked` finds unmarked (138 of 163); `--dialect=unicon` is in `COMPILE_ARGS_ADMITTED` (corpus_suite_harness.py). The vendored sources stay verbatim. Gate `test_gate_icn_a_markerless_unicon_program_prints_unicons_name_form_when_the_driver_is_told_so_in_both_modes.sh`.
- **The Unicon state is read in lower**, not in the runtime (no new global): `cx->prog->v.ival` in lower_icon.c selects the Unicon form of a builtin or an iteration. Today: `name()` of a variable reference becomes `ICN$UNAME` (`table_1["abc"]`, `list_1[3]`, `record complex_1.r`, a section `s[2:4]`; the list-element and field traps carry their container in the `sv` word, rtx_icnsub.s and its C twin), `key(list)` becomes the IR_ITERATE form `ukey` (`rt_list_bang_ukey_at`, indices 1 to *L; plain Icon still raises 124), `system(s)` becomes `ICN$USYSTEM` (the exit status; Arizona returns the raw wait status, 768 for exit 3). NOT granted and so NOT done: sixteen-digit real printing (the cto ruled one word of per-program runtime state `real_digits`; the grant is Lon's, in-chat), which blocks checkc checkx ck checkfpc checkfpx overflow tprintf ilib and uni_class_hello.
- **R3 the class model is Unicon's own translation, done by lower**: the parser builds a `TT_CLASS` node as written (name, superclasses, fields, methods as procedure subtrees, `initially`, `abstract method`); `lower_icon_class.c` translates it as unicon does (the two records, the operations record, the constructor, dispatch, inheritance, initially chaining). No method table searched by name at run time, no new DESCR kind.
- **R4 packages, import and link**: `package p` mangles every global of its file to `p__name` at lower (so its `main` is `p__main`: a package file is not a program); `p::name` names it; `import p` makes p's names visible and links the package's files, found by `icn_resolve_imports` as `p.icn` or as the `.icn` files of a directory that declare `package p`, searched beside the program and then in `IPATH`/`ICONPATH`; `::name` names the unmangled global.
- **R5 the builtin families, ranked**: class reflection; the list and string extensions and `&now`, `&errno`, `&pick`; the pattern type; then posix, thread, crypto and loading as their own rows. **R6 the syntax beyond the words**: class, package and import declarations, `obj.m(args)`, `::name`, `??` and the pattern operators in `icon_parse.c` and `icon_lex.c` under the marker flag. **R7 the suite**: UniTests to 100 of its graded denominator.

## 2. The pattern type: `s ?? p` on the scan road (ARCH-UNICON 2.1, 2.2 and CTO-476, now in this page)

- `s ?? p` is an Icon scan (`lower_pmatch` in lower_icon.c) whose body is the SNOBOL4 match boxes on the scan registers r13 r14 r15 (Σ δ Δ): `|( \1( i := nx to *&subject+1 & &pos := i & PATTERN-BOXES & en := &pos & nx := (en > i | i+1) & &subject[i:en] ) )`. There is NO MATCH_BEGIN/END. unicon's rule, measured: matches are non-overlapping, the next attempt starts at the previous END, an empty match repeats forever (a test needs limits), `Pos(n)` is cursor n-1 and n <= 0 counts from the end, Tab/Rtab can move backwards, a failed attempt commits no `->`.
- Inline boxes for Len Pos Rpos Tab Rtab Any NotAny Span Break Breakx Rem Arb with constant or computed operands; every other element is a VALUE built by the `SNO$PB*` constructors, assigned to a hidden global `$pmgN` and matched by IR_MATCH_DEFER. A pattern with such an element is a COMMIT pattern: `lower_pm_boxes` brackets it with `IR_MATCH_CASMARK`: ival 0 pushes the SCAN MARKER on the r12 island, ival 2 syncs Σ/Σlen, ival 1 pops; the FLUSH (IR_MATCH_FENCE0 with the literal 3) runs the conditional assignments recorded since the marker.
- **The scan marker (CTO-476)**: a 24-byte island entry whose first word is null (the pump and the FLUSH walk skip it as before), word 1 = the activation base (rbp), word 2 = a pointer to the procedure's name, both compile-time facts (the emitter hands the name through the node's sval; CASMARK reuses `ival` for the variant, so a name is told apart by magnitude: `(uintptr_t) ival > 0xFFFF`). Readers: `rt_dcap_pump` walks its entries down from `c->cur` to the first null varname, resolves a capture target with `rt_icn_local_cell_in` (locals by `rt_proc_loff`, parameters by the frame map's argument offset read BY NAME with `rt_icn_proc_args_off` in gc_heap.c, never a frame walk) and skips the asm fast run (its name cache answers from the NV table); `ICN$UPVAR` (builtins row 1258) reads the island top mirror (`RT_DCAP_TOP`) and walks down to the nearest marker. A deferred call inside a recursive procedure therefore sees the activation whose attempt is in flight (witness `uni_pm_defer_rec`).
- **Lowering**: `=>` is a conditional capture followed by FLUSH, so every write to an Icon local goes through the one pump; `.>` is a conditional capture of the empty pattern whose name carries a leading control-C (the pump assigns cursor+1, 1-based, as unicon) followed by FLUSH; a backquoted expression becomes a hidden procedure `$dfN` (`icn_expand_deferred`, lower_icon_class.c) whose free variables read through `ICN$UPVAR`, a call being a success test (the call and the empty string: unicon does not match its value), a variable matched as its value; `&&` is `||`. A capture target is a NAME resolved at match time (R-B5), a file target writes the text.
- **Known red, routed**: a DEFER inside an `every` loop ends the loop after its first body (the blob keeps ~128 bytes of spine, the planner models 16, the UNMARK chain arm trusts the boxes); a while loop leaks 112 bytes a pass. Row `shared-icon-a-pattern-with-a-non-box-element-matched-by-ir-match-defer-inside-an-every-loop-...`, hq_zetas. It blocks rung46_alternation.

## 3. Threads (rung 48, not built)

`thread E`, `wait(t)`, `critical M: E`, `mutex()` parse nowhere yet (the words are only markers). The plan in hand: a thread is a co-expression the scheduler starts; the deterministic subset first (the thread runs to completion before the creator continues, `critical` evaluates its body, `wait` succeeds), blocking forms (channels, condition variables, an empty queue) need a real scheduler over the co-expression switch (`rt_coexpr.c`, `scrip_coexpr_activate`). Ask the cto before the scheduler: the thread family is R5 (5).

## 4. The UniTests package (`corpus/packages/icon/unicon_tests/`, suite key `unitests`)

- Unicon's own tests (`/home/resources/unicon/tests`, 267 programs, 200 `.std`): 163 absorbed in `ALL.icn/ALL.ref/ALL.csv/PARTITION.tsv`, 58 excluded by class in `EXCLUDED.tsv` (graphics, database, bench library modules, the oracle's non-answers CEO-1696), five package-import tests shipped ungraded. Refs are cut by unicon through `unicon_bin()` (CONTRACT.tsv `oracle unicon`), never from a `.std` alone, never from SCRIP. The coo grades the whole package (runner `test_icon_unicon_suite.sh`, `README_RUNNER`); a seat grades a program with `corpus_suite_harness.py run ... --lang icon --modes m3,m4 --partition entry:NAME` (at most eight) and then `s4e_test_request.sh unitests ENTRY...`.
- **Unicon's sources have no semicolons** (newline insertion) and SCRIP Icon requires them (CEO-495), so the package carries the CONVERTED text: `harness/scripts/util_icon_semicolons.py` inserts them where the strict parser asks, and applies the oracle's rule where the parser cannot see it (`tokens.txt` in `/home/resources/icon-master/src/common`: an ender at a line end followed by a beginner). Its traps, all cured 2026-11-04: `$)` is one token; `return`/`break` at a line end swallow the next statement and a line opening with `&keyword` parses as a conjunction (so `preinsert` applies the rule); the parser's reported column can sit inside a string or a real literal (`settle`); a refused file is not written. After ANY conversion audit that every inserted `;` follows a token end (compare each line with upstream after removing the inserted `;`: `-0.5` once became `-0.;5` and its ref was cut from a wrong program).
- **Re-cut the container after any source change**: remove `ALL.icn ALL.ref ALL.csv ALL.in ALL.wantrc ALL.excluded.txt PARTITION.tsv` in the package folder, run `util_build_package_suite.py corpus/packages/icon/unicon_tests --lang icon --twice` (about 12 minutes, waits for a run slot), then `util_suite_partition.py build .../ALL.csv`. `ALL.csv`'s compile_args is rebuilt from CONTRACT.tsv. A converted file the converter still refuses names its cause: numeric suffixes `1k`, `[,]`, `[: :]`, triple strings, `import lang`, `$define` macros with parameters, class fields with `:`, `link cfunc`, the regex literals `<...>` (pattern/r*), `link posix`, the thread keyword.
- `import lang`: the package is the files of `/home/resources/unicon/uni/lib` that declare `package lang`; `icn_resolve_imports` already searches IPATH, so the harness needs the path or the package vendored. Facts measured on unicon: integer literals take `K M G T P` (x1024^n, also `numeric("3k")`); `record x(..)` takes NO `;` and `procedure p();` does; unicon sorts integers and reals as one numeric class; `posix/system` is racy (the child's stderr against the parent's stdout).
