The record is `.github/GOAL-PROLOG-100.md` (LIVE CURSOR on top). Verified 2026-11-01 against SCRIP 9cb24d2ca; the Prolog ARCH pages are retired into this skill and `prolog-engine`, `prolog-tabling`, `prolog-constraints` (`.github/RETIRED-ARCH-PAGES.tsv` reads any of them at its last commit).

## 1. The oracles and the dialect rule (CEO-391, CEO-1772, CEO-1632)

- SCRIP Prolog is the **ISO superset**: ISO 13211-1 is the core and the default; every non-conflicting GNU Prolog and SWI-Prolog builtin is added. **There is no compatibility switch, ever.** Where the oracles conflict, the program's OWN dialect decides, read from markers in the source (`:- use_module(library(...))`, SWI-only syntax such as dicts or `=>`, a `:- set_prolog_flag(double_quotes, ...)`, an XSB `:- import ... from ...`): the SWI dialect answers as `swipl` 9.0.4, the GNU dialect as `gprolog` 1.6.0, the XSB dialect (the third value of the one record, grown from measured differences) as XSB 5.0.0 for the `xsb_tests` package only. A markerless program is the ISO default, whose ref `swipl` cut.
- Oracle binaries go through the accessors, never a bare name: `gprolog_bin()`, `gplc_bin()`, `xsb_bin()` in `harness/scripts/lib_oracle_flags.sh`; `swipl` is on PATH (9.0.4). `test_gate_no_bare_gprolog_or_gplc_outside_the_accessors.sh` and `test_gate_no_bare_xsb_outside_the_accessor.sh` block.
- **A ref is cut from the oracle, never from our output; there is no XFAIL** (CEO-753). What the oracle refuses, crashes or hangs on is `NO_ORACLE_ANSWER`, excluded (CEO-1696); an answer that is an accident of the oracle's implementation is no answer (CEO-1934); everything the oracle answers is debt. OUTSIDE-BASELINE (surface neither ISO nor the superset carries, might be reached) and ORACLE-DIVERGENT (we decided not to reach it, the oracle is outside the standard) are different facts named on the row.
- Floats write at the dialect's precision (XSB 15 digits, GNU 17, SWI shortest round-trip); `/` on two integers is a float in XSB and GNU and exact in SWI (`prefer_rationals`); integers are unbounded in SWI and the default, bounded in XSB and GNU by the flags row.

## 3. The source map

- Parser: `SCRIP/src/parsers/prolog/` -- `prolog_lex.c`, `prolog_parse.c` (operators, the reader, DCG translation `dcg_pass_unify` under the SWI test), `prolog_lower.c`, `prolog_driver.c` (dialect detection, prelude composition), `prelude/*.pl` (the vendored SWI libraries: clpfd, chr, assoc, aggregate, apply, ...; the list `prolog_prelude_libs.inc` is generated by `util_gen_prolog_prelude_libs.py`, never edited), `pl_cell.h`.
- Lowering: `SCRIP/src/lower/lower_prolog.c` (clauses to boxes, first-argument indexing, the cut barrier, catch/throw, the database roads), `lower_prolog_chr.c`.
- Runtime: `SCRIP/src/runtime/` -- `rt/rt_pl_trail.c` and `rt/pl_trail_layout.h` (the trail and choice records on r12: one of the two permitted r12 islands), `rt/prolog_atom.c` (the interner), `rt/pl_rational.h` and `pl_rat.c` (rationals), `unification.c`, `by_name_dispatch.c`; the Prolog asm leaves in `rtx/rtx_plunify.s` (skill `prolog-engine`). Prolog uses `DESCR`, not a `Term` type (Lon s273); allocations ride the three zetas in order (SPINE, ACTIVATION FRAME, STANDING FRAME); only string VALUES go to the heap, never structure.
- Pipeline: parser → lower → optimizer → planner → the one emitter. `./scrip --dump-ast|--dump-ir|--dump-bb|--dump-zeta|--dump-plan prog.pl`. Every goal is a four-port Byrd box (α β γ ω); a bounded (deterministic) box emits no β and allocates no choice point; the boxes ARE the engine, there is no central solve loop (skill `prolog-engine`).

## 4. The dialect record (one front end, three dialects, decided in the lowerer)

| dialect | what makes a program this dialect | oracle |
|---|---|---|
| GNU / ISO (the default) | no SWI or XSB marker in its own clauses | GNU Prolog 1.6.0 (`gprolog_bin()`, `gplc_bin()`) |
| SWI | its own tree carries a construct gprolog refuses or does not read: `:- module/2`, `:- use_module/1,2`, an SSU rule `Head => Body`, a dict literal or dict dot | SWI-Prolog 9.0.4 |
| XSB | an XSB marker (`:- import P from M.`, `:- compiler_options(L).`, `:- index`, `:- hilog`, `:- ti`), which outranks an SWI marker | XSB 5.0.0 (`xsb_bin()`) |

Markers are grown by measurement, never by taste (CEO-1632); a marker counts only in the program's own clauses (the prelude never decides); once one file of a program is SWI the program is. Decided in the lowerer's first pass (`pl_dq_lower_program`), kept on the stage record (`pl_dialect`, `pl_dialect_swi`, `pl_dq_mode`), never a bare global. The switches on the record: the `double_quotes` default (an SWI string object against an ISO code list; an explicit flag wins); `display/1` (SWI's through `'$display_swi'/1`); `print/1,2` (SWI quotes); the list constructor's NAME (`'[|]'` in SWI, `'.'` elsewhere, one representation, read through one accessor at the roads that spell a cons by name); float printing (XSB 15 digits, GNU 17, SWI shortest round trip); `Int / Int` (a float in XSB and GNU, exact in SWI); `max_integer` and wrapping (XSB and GNU bounded); XSB's `functor/4` reached only by its import. A later conflict between the oracles is one more switch, ruled the same way.

### ENTRY-POINT CONVENTION (hq_C ruling 2026-08-29; gate `test_gate_prolog_entrypoint_ruling.sh`)

`main/0` auto-invoke is SANCTIONED: SCRIP runs a file's `main/0` when no `:- initialization(main).` asks for it, and on a directive-less file `swipl -q -g main -t halt` and `scrip` are byte-identical. The oracle's invocation is chosen per file on the presence of a directive, never fleet-wide (`-g main -t halt` runs main twice on a file that carries the directive). Load-time directives run in place in source order whether or not `main/0` exists, and a directive-only file is legal Prolog (both were cure rows, now DONE). A failure-driven `main` with no fallback clause exits 1 as a top-level goal does: graded stdout against the oracle and rc against the expectation declared in its ref, per file.

### The database, modules and streams: the rulings (the cto, 2026-10-24 to 10-31, CEO-1964/1971/2029/2030/2064)

1. `readutil` is base-prelude Prolog, not C: the vendored `readutil.pl` takes its foreign branch and the prelude defines `read_stream_to_codes/2,3` and `read_line_to_codes/2,3` as swipl's C does (CR kept in `/3`, dropped in `/2`).
2. The prelude is autoload: a user definition wins whenever it arrives (a library predicate is linked only when the program leaves it undefined).
3. In the SWI dialect a user clause for an `iso` builtin is a `permission_error`; for any other builtin it defines the predicate in user (`pl_user_file_defines`), the iso set cut once from swipl.
4. `listing/1` and `portray_clause/1` print swipl's layout in the SWI dialect (`library(listing)` vendored); `predicate_property(H, meta_predicate(Spec))` is one record column read at run time.
5. The clause fragment compiles lazily; a consulted static predicate lowers whole at its first call; the fragment chain is the dynamic predicate's alone.
6. The module context: the surface is swipl's compound `M:G`; the mangled key `'M:p'` is the registry's alone; a prelude library's clauses carry their module as a consulted module file's do.
7. The dynamic fact table is indexed on its first argument; the facts-only data path goes ahead of the lazy compile; a non-ground fact takes the data road with one whole-head copy.
8. `call_with_depth_limit/3` is lowered from the frames (Lon's grant, CEO-2010); `call_with_time_limit/2` is a DUE word in the thread's trail header (`PL_TR_ALARM_*`), consumed by the blocking leaves at EINTR and by one emitted probe at a recursive predicate's α (`poll_alpha`).
9. A stream's column counter is the stream record's; `library(process)` and `library(socket)` are leaves over the one stream table.
10. `read_term/2`'s `subterm_positions` and `comments` follow swipl, dicts included (`dict_position`, `key_value_position` in source order); a comment inside a term stays in the text the reader parses, so every position after it counts it as swipl does.
11. The fresh variables of one body term are created in source order, left to right.
12. Goal expansion happens where a clause is lowered, under a per-unit fact the loading directive sets.
13. Program space is one counter per module, read by `module_property/2`, limited by `set_module/1`.
14. A conditional-compilation chain on a user goal becomes one run-time directive that consults the chosen block's text through the run-time loader.
15. A consulted clause keeps its source file and line beside its slot (the seed and consult roads set them); its variable names are re-read as swipl re-reads them, never stored (DESIGN-PLAN consulted-clause-source-record, all eight steps DONE).
16. An erased slot's term is released under the oldest live walk's generation, a frame word the map names.
17. A module's import list is a run-time table built at the module flatten (CEO-2109): each `use_module(library(L), [N/A, ...])` or `autoload/2` import into a module other than `user` becomes one static fact `'$mod_imp'(Module, N, A, Key)`, Key the library's private key (`L:N`, or `system:N` when the base prelude holds the export); the table is code in the registry, never a global, never grown at run time. The qualifier is the carrier: in the program's own non-user modules (plunit units excepted, they keep `'$mctx_call'`) a VARIABLE meta argument (`0` or a closure position: `call/N`, `findall/3`, `forall/2`, `\+`, `maplist`, a declared meta-predicate) is wrapped `M:V` at the flatten, and lower takes a constant-module goal whose goal is a variable to `'$mod_call'(M, V)` instead of dropping the module. At run time the `M:G` road (`'$mod_qb'`) and the closure road (`':'/3..11` through `'$mod_exti'`) look up `'M:N'` first, then M's import table, then the plain key. A qualifier chain is stripped to its INNERMOST module everywhere a road strips one (the tabling prelude's `'$tbl_strip'` included), since the wrap qualifies a goal that may already carry its caller's module. Witness `corpus/tests/prolog/module_import_table/mit_meta_call.pl` (swipl's 71 through `call/1`, `maplist/3` and `findall/3`; `user:N` still reaches the user's clause).

### Rationals (swipl's, on the runtime's one rational record)

A rational is a number (`1r3` literal syntax, written back as `1r3`; normalized, a denominator of 1 collapses to the integer); evaluables `rdiv/2`, `rational/1`, `rationalize/1`, `numerator/1`, `denominator/1`, and the arithmetic family accept them; standard order compares by value. Represented by the runtime's existing arbitrary-precision rational record (`rk_rat_new`, `rk_rat_is`, normalized by `rq_make`): no new tag, no new block type, no new visitor; the runtime branches on the value, never on the language.

### Where the downloaded programs live

ProRosetta and PasRosetta are the Rosetta Code tasks for Prolog and Pascal, refs cut from the oracles (Rosetta Code's own printed outputs are not refs); the standardpascaline and tex programs feed PasDemo (skill `pascal`).

## 6. Debugging a Prolog red

1. `bash ../harness/scripts/monitor_run.sh prog.pl --oracle` (gprolog's `gpx` by default; `MONITOR_PL_ORACLE=swipl` for `swx`): the bug lies between the last event both agree on and the first they diverge on. `--trace`, `--modes`, `--input FILE`.
2. ASM-DIFF-FIRST: the smallest repro beside a passing sibling, `--compile` both, diff within one mode.
3. `util_diagnose_prolog_swi.sh <case>` for a SWI case; `util_swi_red_census.py` for the red classes; `util_xsb_oracle_runs.py` for an XSB ref.
4. Only then gdb with a breakpoint and a hit count.

## 7. Rulings a Prolog landing must not break (receipts in GOAL-PROLOG-100.md and GOAL-CEO.md)

- A cure that trades one program for another never lands (CEO-589); the re-grade of the cured program AND the Prolog smoke (`test_smoke_prolog.sh`) run before the push; a prelude or runtime change is shared code (all eight smokes).
- No `Term` surface, no new heap allocation of structure, no second stack, no C function entering a box (CEO-1576); a C road out of a box returns an address and the box jumps.
- The trail is unconditional today; a landing that touches trailing reads skill `prolog-engine` first.
- Directives run in place in source order as swipl; `initialization(main, main)` exits with main's status; errors carry swipl's culprit and context under the SWI dialect, gprolog's under GNU (the `test_gate_pl_*_as_swipl.sh` and `_as_gprolog.sh` gates are the witnesses: 150+ of them, each a ruling).
- A grammar or operator change is invisible until `regenerate_parser_and_lexer_from_sources.sh` runs; `util_gen_gc_allocating_table.py --check` must read rc 0 after any runtime function that allocates is added (a Prolog landing of 2026-10-30 left it red: regenerate, never edit).
- The planner, never the emitter, decides a home (CEO-1895); a landing that moves Prolog placement names the measured counts in its commit.
