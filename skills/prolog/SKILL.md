# SCRIP Prolog

The record is GOAL-PROLOG-100.md (LIVE CURSOR on top); a page beats this skill. Suite tables, file maps and receipts in full are in `reference.md` beside this file.

## 1. The oracles and the dialect

- **The ISO superset** (CEO-391/1772): ISO 13211-1 is the core and default, plus every non-conflicting GNU and SWI builtin. No compatibility switch, ever.
- **The program's own dialect decides a conflict**, read from its markers (`use_module(library(...))`, dicts or `=>`, a `double_quotes` flag, an XSB `import ... from`): SWI answers as `swipl` 9.0.4, GNU as `gprolog` 1.6.0, XSB as XSB 5.0.0 (the `xsb_tests` package only). Markerless is ISO, ref cut by `swipl`.
- Oracles through `gprolog_bin()`, `gplc_bin()`, `xsb_bin()` in `harness/scripts/lib_oracle_flags.sh`, never a bare name.
- A ref is cut from the oracle; no XFAIL; refusal, crash or hang is `NO_ORACLE_ANSWER` (CEO-1696); an implementation accident is no answer (CEO-1934).
- Floats print at the dialect's precision (XSB 15, GNU 17, SWI shortest round-trip); `/` of two integers is a float in XSB and GNU, exact in SWI; integers are unbounded in SWI and the default.

## 3. The source map

- Parser `src/parsers/prolog/`: `prolog_lex.c`, `prolog_parse.c` (operators, the reader, DCG), `prolog_driver.c` (dialect detection, prelude composition), `prelude/*.pl` (vendored SWI libraries; the list generated by `util_gen_prolog_prelude_libs.py`).
- Lowering `src/lower/lower_prolog.c` (clauses to boxes, first-argument indexing, cut, catch/throw, the database), `lower_prolog_chr.c`.
- Runtime: `core/rt_pl_trail.c` (the trail and choice points on r12), `core/prolog_atom.c`, the Prolog rtx leaves. Prolog uses `DESCR`, not a `Term` type; only string values go to the heap, never structure.
- Every goal is a four-port box; a bounded box emits no β and no choice point; the boxes are the engine, no solve loop.

## 7. Rulings a landing must not break

- A cure that trades one program for another never lands (CEO-589); the cured program re-graded and `test_smoke_prolog.sh` before the push; a prelude or runtime change runs all eight smokes.
- No `Term` surface, no heap structure, no second stack, no C function entering a box (CEO-1576): a C road out of a box returns an address and the box jumps.
- Trailing is unconditional today, conditional in design: a landing that touches it cites ARCH-PROLOG-THREE-ZETAS.md.
- Directives run in place, in source order, as swipl; `initialization(main, main)` exits with main's status; errors carry the dialect oracle's culprit and context (the `test_gate_pl_*_as_swipl.sh` and `_as_gprolog.sh` gates are the rulings).
- Regenerate after a grammar or operator change; `util_gen_gc_allocating_table.py --check` reads rc 0 after any allocating runtime function is added (regenerate, never edit).
- The planner, never the emitter, decides a home (CEO-1895); a landing that moves placement counts names them in its commit.
