# SCRIP Prolog

The record is GOAL-PROLOG-100.md (LIVE CURSOR on top). Suite tables, the dialect record, the entry-point convention and the database rulings in full are in `reference.md` beside this file.

## 1. The oracles and the dialect

- **The ISO superset** (CEO-391/1772): ISO 13211-1 is the core and default, plus every non-conflicting GNU and SWI builtin. No compatibility switch, ever.
- **The program's own dialect decides a conflict**, read in the lowerer from its markers (`:- module`, `:- use_module`, `=>`, dicts make it SWI; `:- import ... from`, `:- compiler_options`, `:- index`, `:- hilog` make it XSB; neither is GNU/ISO). SWI answers as `swipl` 9.0.4, GNU as `gprolog` 1.6.0, XSB as XSB 5.0.0 (the `xsb_tests` package only). Markers are grown by measurement (CEO-1632).
- Oracles through `gprolog_bin()`, `gplc_bin()`, `xsb_bin()` in `harness/scripts/lib_oracle_flags.sh`, never a bare name.
- A ref is cut from the oracle; no XFAIL; refusal, crash or hang is `NO_ORACLE_ANSWER` (CEO-1696); an implementation accident is no answer (CEO-1934).
- Floats print at the dialect's precision (XSB 15, GNU 17, SWI shortest round-trip); `/` of two integers is a float in XSB and GNU, exact in SWI; integers are unbounded in SWI and the default.

## 6. Debugging a red

1. `bash ../harness/scripts/monitor_run.sh prog.pl --oracle` (gprolog's `gpx`; `MONITOR_PL_ORACLE=swipl` for `swx`).
2. Asm-diff the smallest repro beside a passing sibling within one mode.
3. `util_diagnose_prolog_swi.sh <case>`, `util_swi_red_census.py`, `util_xsb_oracle_runs.py`; `SCRIP_PL_TRACE=1` the port tracer.
4. gdb last, with a breakpoint and a hit count.

## 7. Rulings a landing must not break

- A cure that trades one program for another never lands (CEO-589); the cured program re-graded and `test_smoke_prolog.sh` before the push; a prelude or runtime change runs all eight smokes.
- No `Term` surface, no second stack, no C function entering a box (CEO-1576): a C road out of a box returns an address and the box jumps.
- Directives run in place, in source order, as swipl; `main/0` auto-invoke is sanctioned (the ENTRY-POINT CONVENTION, `reference.md` § 4); `initialization(main, main)` exits with main's status; errors carry the dialect oracle's culprit and context (the `test_gate_pl_*_as_swipl.sh` and `_as_gprolog.sh` gates are the rulings).
- Regenerate after a grammar or operator change; `util_gen_gc_allocating_table.py --check` reads rc 0 after any allocating runtime function is added (regenerate, never edit).
- The planner, never the emitter, decides a home (CEO-1895).
