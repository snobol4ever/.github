## 1. The call protocol's entry points (all in `src/runtime/rt/rt.c` unless named)

- Registry: `rt_proc_register`, `rt_proc_register_rec` (mode 4's startup), `rt_proc_find`, `rt_proc_hash_lookup`, `rt_proc_index_of`, `rt_proc_is_registered`, `rt_proc_is_generator`, `rt_proc_is_defined`, `rt_proc_is_redefined`, the `rt_proc_set_*` setters (`_nformals`, `_nparams`, `_rest_kind`, `_jmpentry`, `_zstatic`, `_generator`, `_dyn_scope`, `_frame`, `_locals`), `rt_proc_unregister`, `rt_proc_reset`.
- Opening a call: `rt_proc_call_open` and its forms `_det`, `_det0`..`_det4`, `_fnret`, `_p`, `_pn`; `rt_call_open_staged`, `rt_call_open_staged_rec`, `rt_call_open_tail`, `rt_call_open_tail_lex`, `rt_call_open_found`, `rt_call_open_by_name`, `rt_call_open_by_name_p`, `rt_call_named_open`, `rt_call_named_proc`, `rt_call_proc`, `rt_call_proc_descr`.

- DEFINE: `rt_proc_define`, `rt_define_site`, `rt_define_site_entry`, `rt_define_bind_entry`, `rt_define_query`, `rt_define_tiny_ok`.
- Generator procedures: `rt_genp_spine_enter`, `rt_genp_thread_entry`, `rt_genp_entry_c`, `rt_genp_yield`, `rt_genp_deliver_γ`, `rt_genp_deliver_ω`, `rt_genp_destroy`, `rt_genp_lookup`, `rt_proc_call_gen_h`.
- The mode-3 thunks `rt_outer_call` and `rt_outer_call_root` (inline asm in `src/driver/scrip.c`).

Rules from the protocol's history that stand: the regime is recorded on the record (`jmp_entry`), never re-derived from the emit side; only formals bind, every prototype name is saved and nulled, excess actuals are evaluated and ignored (SPITBOL ch. 8); a record field the asm reads is appended last and pinned by a static assert; NRETURN is a γ citizen yielding a NAME.

## 2. The builtin table in full (DESIGN-PLAN builtin-table, CEO-2016)

- **The laws**: language identity stops at lower; a runtime entry is named on the node as data; no C function enters a box (`conv=open` returns the address); logic lives in boxes; no accessor layer; no fixed limit (what a program adds at run time, an OPSYN alias or a user class's methods, lives in a rooted growable structure); large chunks; every step keeps every suite row.
- **The row**: `bid` (never renumbered or reused), `vocab` (`sno` for SNOBOL4 with Snocone and Rebus, `icn`, `rk`, `rkm` for a Raku method, `pas`, `pl`, or `all`), `name`, `min`/`max` (the lowerer pads below `min` with the vocabulary's null and applies its over-arity rule above `max`; a leaf never counts arguments), `entry` (what the emitter calls directly; a leaf row's slot is the symbol `bt_<name>`, and when the entry is another symbol the entry is the fast form and the complete chain arm's body moves into the `bt_` leaf, no wrapper, CTO-493), `conv` (`leaf` `DESCR_t f(DESCR_t *args, int nargs)`; `gen` with a state word the box keeps in its carve; `open` returning an address to enter; `inline`, emitted by a template), `recv` (a method's receiver class), `flags` (`scan`, `mut`), `op`. A name with two meanings is two rows. `alloc` is derived, never a column. SPITBOL refuses redefining a system function (error 248), so no shadow flag exists.
- **Lower resolves**: the program's own definition wins and is checked first; `lower_call_road_kind` reads the row (`leaf` to `IR_CALL_DIRECT`, `gen` to `IR_CALL_GEN`, `open` to `IR_CALL_METHOD`, `IR_CALL_REDISP`, `IR_CALL_APPLY` or `IR_CALL_EVAL`, `inline` to `IR_CALL_PL_LEAF` or `IR_CALL_PAS_BI`); no row and no definition is `IR_CALL_BYNAME`, the one dynamic road.
- **The emitter reads the row and decides nothing**; no builtin name is emitted as a `.string` on a resolved call.
- **The steps**: 1 the table [hq_runtime, DONE]; 2 every chain arm a leaf [hq_runtime, ASSIGNED]; 3 resolution in lower, SNOBOL4 first [cfo]; 4 Icon [hq_icon]; 5 Raku with the method table by class and bid [hq_raku]; 6 the dynamic road and the deletion of the by-name chains (`try_call_builtin_by_name`, `rt_builtin_is_known`, `rt_builtin_is_generator`, `rt_str_method`, `g_bn_direct`, `icn_bi_tbl`) [hq_runtime]. The step harness is `test_design_builtin_table_steps.sh`; two instruments the plan names are not built yet (`util_call_box_census.sh`, `test_gate_no_builtin_name_strcmp.sh`).
- **Forbidden**: a builtin name as a `.string` on a resolved call; a name list anywhere but the TSV; a `strcmp` on a builtin's name in `src/runtime`; a fifth `conv`; a run-time insertion into the static table; a run-time rebinding of a resolved builtin.

## 3. The error protocol in full (DESIGN-PLAN exceptions, CEO-2020)

| language | raises today | the catch construct | class |
|---|---|---|---|
| Prolog | ISO errors from C leaves, `throw/1` | `catch/3` as today (the model: `PL_BALL_ARM`, `PL_BALL_DROP`, `PL_BALL_GET` in `rtx_plunify.s`; `x86_pl_ball_rule_omega`; `bb_gate.cpp`; `rt_pl_catch_handle_c`) | HANDLED |
| Icon | `core_icn_error`, `runerr`, the `&error` keywords | none for conversion; the root for FATAL | CONVERTED / FATAL |
| SNOBOL4, Snocone, Rebus | `&ERRLIMIT`, SETEXIT, `:(CONTINUE)`, `:(ABORT)`, `:(RETURN)`, EVAL and CODE errors | the statement as a catch construct when the graph uses SETEXIT; EVAL and CODE call boxes | CONVERTED / HANDLED / FATAL |
| Raku | `die`, `fail`, `X::*`, `try`, `CATCH`, `.rethrow`, `orelse` | `try`; CATCH's `when` clauses are the handler's arms | HANDLED / FATAL |
| Pascal | division, range, nil, I/O run-time errors | the root | FATAL with fpc's exit code |

The steps: 0 the baseline [cto]; 1 the ball record and the root, beside the old road (`rt_raise`, `rt_ball_t`, `rt_root_ball_exit`) [cfo, ASSIGNED]; 2 the ω ball test and the catch gate (`planner_raises`, `x86_ball_test_omega`, `lc_catch`) [cfo]; 3a and 3b the shared runtime returns verdicts (`core.c`, `coerce.c`, `keywords.c`, `aggregates.c`; then `string_ops.c`, `arithmetic.c`, `pattern_match.c`, the two hot catchers deleted) [cfo]; 4 Icon [hq_icon]; 5 SNOBOL4, deleting `rt_return_to_emitted`, `rt_setexit_fire_now`, `sno_setexit_fire_on_end`, `rt_goto_transfer` [hq_snobol4]; 6 Raku, deleting `g_rk_cbh_cur` [hq_raku]; 7 Pascal [hq_pascal]; 8 Prolog joins the shared record [hq_prolog]; 9 the deletion of `core_runtime_error`, `core_icn_error`, `core_errjmp.h` and every `setjmp` but the co-expression thread exit [hq_runtime]. A language's step never lands before 3b. Harness `test_design_exceptions_steps.sh`; the ratchet `test_gate_no_c_to_bb_ratchet.sh`.

What a builder must not do: add a `setjmp`, a handler chain, a snapshot, `_Unwind_Backtrace` or an `exit()` outside the root and the resource refusals; decide in C whether an error is handled; propagate a ball β by β; price the ball's landing from anything but the catch gate's planned depth; print the voice anywhere but the root, twice, or to stdout; change what the oracle says the language surface means.

**P7, the resource edge** (2026-10-30): today `rt_stack_overflow_sig` (`rt_stack_overflow.c`) prints ERROR 246 and exits on a fault below the adopted stack (`rt_main_stack_adopt`, the declared `-s` with one guard page), and the heap cap has a catchable road where `hp_cap_road` is declared (the Prolog trail). The design: a catch gate carves a catch record in its own cell and links it from the trail header, the overflow handler resumes at the innermost record with the ball armed (resource step 1); a recursive C leaf asks `rt_stack_refuses(bytes)` first; a bulk heap request asks `rt_pl_cap_asks(bytes)` first and takes a RETRY verdict the poll serves (resource step 2); the stack limit flag is the unit's declaration (resource step 3). Witnesses `corpus/tests/prolog/resource/`. All three steps are FREE.

## 4. The crossing law between graphs (Lon 2026-08-20, PRIORITY ONE: "Get a reliable way to go between BB's. Each BB graph has TWO continuations.")

- **Partition by activation**: the unit of a crossing is an activation, a closed set with exactly two exits, γ succeed and ω concede; every seam question is answered at an activation boundary, never mid-box.
- **Two continuations, one discipline**: a graph's external contract is the pair {γ, ω}; a crossing banks the caller's pair, installs the callee-relative pair, runs, and the callee's γ or ω restores the banked pair. Nothing else carries cross-graph linkage. The pair is activation state: whatever holds a suspension holds the banked pair, and a β re-entry reinstalls it.
- **The push-pair move**: the caller pushes the γ and ω landings as return locations and the exit chooses between them; r10 and r11 are not wire registers (they hold the statement number and the box id). Two return protocols share the call arms, and `rt_define_returns_by_frame` says which a callee uses (the floater consumes the pair at the top of the stack, a plain jmp-entry body takes its wires in registers and keeps them in its frame).
- **Retire against suspend**: RETURN (γ, done) retires the frame and restores the depth; a suspend (a yield) leaves the frame live and jumps to the landing; the two exits have opposite frame lifetimes and never share one form.
- **rbp is correct at every β**: a box whose β runs with a stale rbp is a defect whether or not the run survives.
- **No denial**: a failure case is never denied by an admission filter or an "unsupported" arm; it is minimised and fixed.
- History: the law's "RESULT slot for every box at box index times granule" was superseded by the planner's carve per kind (skill `scrip-memory-model`).
