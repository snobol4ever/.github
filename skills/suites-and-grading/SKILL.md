## 2. Grading one program (what a lander does)

```bash
python3 ../harness/scripts/corpus_suite_harness.py run ../corpus/tests/<lang>/ALL.<ext> ../corpus/tests/<lang>/ALL.ref --lang <lang> --modes m3,m4 --partition entry:<name>
S4E_CHUNK=entry:<name> bash ../harness/scripts/test_<lang>_<pkg>_suite.sh
bash ../harness/scripts/test_feature_reps.sh <lang> <feature>
bash ../harness/scripts/test_smoke_<lang>.sh
bash ../harness/scripts/s4e_test_request.sh <suite-key> <entry>...        # at most eight; the coo grades
```

`--modes m3,m4` is mandatory; the two modes may diverge and each is graded against the oracle. A program runs at its DECLARED sizes (the entry's heap and stack, CEO-1353/1281); the declared size is a hard cap and out of stack is a bigger declared `-s`, never data moved.

- **A program's input files and output files are in its current folder** (Lon 2026-11-15 11:4x CST, in the coo's window, verbatim: "The test harness needs to handle programs that a list of input files and output files which of course should always be in the current folder.").
  - Input: an entry's input files are placed in the folder the program runs in. A container entry carries them as its file fences, written beside the program. A files-form package (ALL.source) runs each program in its own folder of the package tree, so the files beside it are there, and its stdin is NAME.in.
  - Output: the `out_files` cell of ALL.csv lists bare file names in that folder. Each is deleted before every run (the oracle, m3 and m4), and its bytes are appended after the run's stdout in the order listed. A file not written is the line `<<out_files: NAME was not written>>`.
  - Both roads do it: the per-entry road (`_out_files_clear` and `_out_files_append` in corpus_suite_harness.py), and `scrip --run-files` for a files-form package since SCRIP 946acf03d (scrip_rl_outfiles in scrip.c), which before deferred every out_files entry.
  - A name with a slash is refused on both roads: the folder is the program's own.
  - MEASURED: vanilla wdstar writes its whole answer to a file named 5000, because SPITBOL reads OUTPUT(.OUTPUT,6,5000)'s record length as a name. It read UNPROVEN while the switch deferred it, and its captured output now equals wdstar.out byte for byte.
- **A program of a package read in place runs in a scratch copy of its folder, never where it stands** (the CAO's finding of 2026-11-15: slobol's `lex.sbl` writes `sbl.lex`, `sbl.com` and `minimal.txt` beside itself, and `asm.sbl` then read them). Both roads keep it: the grade road (`scrip --run-files`, for SNOBOL4, Icon and Prolog alike) and the builder's mine road (`_mine_run`: a copy per worker and folder, made again after any run that changed a file, CTO-583 (2)). MEASURED by the grader 2026-11-16: a planted program that writes `made.txt` beside itself graded PASS on each road and the collection and the package were left as they were. `corpus_suite_harness.py --probe-source` now plants such a program, so a road that ran in place reads `in_place=RED`.

- **`ALL.csv`:** the one index, one row an entry. Every run fact of the entry is a column of its row, the same columns in every suite:

  An empty cell is the default.
