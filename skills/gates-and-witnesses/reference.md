# Gates and witnesses: the reference (the detail behind SKILL.md; read the section you need)

The fleet proves everything by a runnable command that reads RED now and GREEN when the work is done (CEO-1386: a row exists only while a measurement says the problem exists). Four kinds of test carry that: a GATE (a hermetic census or invariant over a population, with a board line and three exit codes), a WITNESS (one program with a ref cut from the oracle, graded in both modes), a RUNG (a witness of one construct on the language's ladder) and a DESIGN STEP HARNESS (the witnesses of a DESIGN-PLAN, step by step). The law is RULES.md (CEO-1386 A ROW EXISTS ONLY WHILE A MEASUREMENT SAYS SO; CEO-1680 NO PLANTED BREAKAGE and THERE IS NO XFAIL; CEO-553/555 a criterion a deletion satisfies is false; CEO-1342/1671/1673/1893/1926/1928/2068 ONE TESTING OFFICER; CEO-1696/1934 NO ORACLE ANSWER → EXCLUDED; CEO-1353/1281 DECLARED SIZES; CEO-576 a gate anchored on a found witness dies the day someone cures it; CEO-1676 STORED PARTITIONS; CEO-2060 A DIRTY-TREE READING IS UNREAD). Lines quoted below are from harness 230edb1 and corpus at 2026-10-31.

## 1. THE RULES (each with its receipt)

- **THREE EXIT CODES, ONE BOARD LINE**: rc 0 GREEN over a MEASURED population, rc 1 RED naming what is red, rc 2 REFUSE when the test cannot measure (no `./scrip`, a stale binary, an empty population, a program that did not compile, a missing oracle); a gate prints one greppable board line (`<NAME>_BOARD lang=<l> ...=<n> programs=<p> (tree <hash>)`) and ends `GATE OK [name]: ...` or `GATE FAIL [name]: ...`. A test NEVER edits itself to return 0; a measurement it cannot take is a refusal, not a pass (`[ "$un" = 0 ] || { echo "REFUSE(2): ..."; exit 2; }`).
- **THE STALE-BINARY PREFLIGHT ON LINE 2** (`util_require_fresh.sh --gate "$(basename "${BASH_SOURCE[0]}" .sh)" || exit $?`: *"THE ONE-LINE STALE-BINARY PREFLIGHT, callable from ANY language ... CONTAINS NO STALENESS LOGIC AND MUST NEVER GROW ANY"*): every gate that grades `./scrip` refuses rc 2 on a binary older than HEAD; rebuild after every commit or the gates refuse.
- **A CRITERION FAILS ONCE BEFORE IT IS TRUSTED, AND NEVER BY A PLANT** (CEO-1680, Lon to hq_snobol4, verbatim: *"Do not add broken code just to enable a test to determine a bug in PATTERN matching is fixed. Just create a proper test instead."*): a new ref is shown red against a corrupted copy, or the gate red on the commit before the cure (`<cure>^`); no test-only seam in the code; a gate that can no longer trip once the defect is cured is dead (CEO-576) and is re-anchored on a synthetic population or deleted with its row.
- **THERE IS NO XFAIL**: the `xfail` column of a suite table is 0 or the entry is EXCLUDED with a reason; a known-red entry stays red on the board as debt (CEO-749/1518); what the oracle cannot answer leaves the denominator as `NO_ORACLE_ANSWER` (CEO-1696/1934); a test that cannot measure REFUSES rc 2.
- **A DONE-WHEN IS A COMMAND, GRADED ON ORIGIN, THAT A DELETION CANNOT SATISFY** (CEO-553: a row retired, not closed, *"its DONE-WHEN would pass on deleting correct code"*; CEO-555: *"a criterion is a hypothesis about what done looks like, and when the measurement contradicts it, the criterion loses"*; `mint` refuses a prose DONE-WHEN and a second column-0 DONE-WHEN): it reads the denominator it grades, never pins a population count, carries its PREMISE-WHEN (what must exist for the question to make sense), and `done` runs it and refuses a red. It begins `cd "${S4E_HOME:?REFUSE(2): S4E_HOME unset}" &&`.
- **A WITNESS IS ONE PROGRAM, ITS REF CUT FROM THE ORACLE, GRADED IN BOTH MODES**: the oracle through its accessor (`sbl_correctness_bin()`, `icont_bin()`/`iconx_bin()`, `swipl_bin()`, `gprolog_bin()`, `xsb_bin()`, `fpc_bin()`, `rakudo_bin()`, `unicon_bin()` in `lib_oracle_flags.sh`; a bare oracle path outside the accessor is a gate's red), run under `timeout -k 5` with `< /dev/null` when it reads no stdin; a `.ref` is bytes, binary to git, compared with `cmp`; `--modes m3,m4` is mandatory and each mode is graded against the oracle, never against the other.
- **EVERY ENTRY DECLARES ITS SIZES** (CEO-1353/1281; `ALL.csv`: `rank,entry,origin,family,kind,xfail,n_lines,heap_kb,stack_kb,compile_args,run_args,<feature columns>`): runners pass `-d<kb>k -s<kb>k` from the row, never an environment knob; the declared size is a HARD CAP; a program out of stack gets a bigger declared `-s`, never data moved to the heap (CEO-1354).
- **A MASTER IS A CONTAINER, NEVER A PROGRAM**: `corpus/tests/<lang>/ALL.<ext>` with `ALL.ref`, `ALL.csv`, `ALL.rc`, `PARTITION.tsv` (built by `util_suite_partition.py build`, regenerated by any landing that changes `ALL.csv`, CEO-1676); the one extraction authority is `corpus_suite_harness.py extract`; the one add-a-witness path is `util_add_ladder_witness.py` (*"Before this script, none existed ... three prior sessions ... hit this exact wall"*).
- **A RUNG IS ≤ 20 LINES, ONE CONSTRUCT, DECLARED NEVER DERIVED** (`corpus/tests/<lang>/LADDER.tsv`: *"THE CONSTRUCT CENSUS. DECLARED, NEVER DERIVED; the LAST rung line is the TOP"*): a declared rung not built is RED; rung N+1 opens when N is green in both modes (`test_<lang>_ladder.sh --to N | --only N`).
- **A DESIGN STEP HARNESS READS A STEPS.tsv** (`step slug executor depends probe witnesses`, most plans adding `ruling landing_files`; skill `design-plans`): `--list` prints the plan, `--step N` grades the step's witnesses in both modes from the witness folder plus the step's probe, outputs under `/tmp` never the root; the DONE-WHEN of a design row is `--list` succeeding and each step's red today recorded on the page.
- **ONE TESTING OFFICER** (CEO-1342 and its amendments): the coo runs suites, boards, the blocking set (`make test`) and the `.s` regeneration, up to FOUR tests at once with one run slot left free (CEO-2068), and alone writes the SUITE TABLE rows; a lander fixes ONE program, re-grades THAT program in both modes, runs `test_feature_reps.sh <lang> <feature>` (≤ 8 core entries, CEO-1677) and `test_smoke_<lang>.sh` for every language its diff touches (all eight for shared code), and asks for named tests by `s4e_test_request.sh <suite-key> <entry>...` (≤ 8 programs); `lib_one_runner.sh` refuses a board (rc 2) to any seat but the runner. `make preflight` is not a per-push check; heavy verification once per batch of 3-4 (CEO-1316).
- **A DIRTY-TREE READING IS UNREAD** (CEO-2060): a board line stamped `-dirty` assembles no row; grade in a clean worktree outside the root; never edit the tree a loop is running on. Every hand run takes a run slot (`util_run_slot.sh`, the `flock` loop over `/tmp/s4e-run-slots/slot0..7`).
- **NO SYMLINKS, NO ENV OVERRIDES, FIXED RELATIVE PATHS** (CEO-1817/1819/1820/1853): a script finds its siblings by `HERE="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"; ROOT="$(cd "$HERE/../.." && pwd)"`; a scratch worktree needs harness and corpus siblings beside it.

## 3. WORKED EXAMPLES (quoted)

A gate in full shape, `test_gate_no_rsp_reset_at_beta.sh` (36 lines): the population from one authority, each program compiled once from its own directory under a timeout, a census over the output, a board line per language and in total with the tree hash, the three exit codes with the refusal reasons named.

```bash
[ -s "$T/list" ] || { echo "REFUSE(2): the population is empty${L:+ for $L}"; exit 2; }
while IFS=$'\t' read -r lang f; do
    i=$((i+1)); mkdir -p "$T/$lang"
    ( cd "$(dirname "$f")" && timeout -k 5 300 "$SC" --compile --out="$T/$lang/$i.s" "$(basename "$f")" < /dev/null >/dev/null 2>&1 ) || { rm -f "$T/$lang/$i.s"; un=$((un+1)); }
done < "$T/list"
echo "RSP_RESET_AT_BETA_BOARD total beta=$tb functions=$tf programs=$tp unmeasured=$un (tree $(git -C "$ROOT/SCRIP" rev-parse --short HEAD))"
[ "$tp" -gt 0 ] || { echo "REFUSE(2): nothing compiled"; exit 2; }
[ "$un" = 0 ] || { echo "REFUSE(2): $un program(s) did not compile -- the count does not cover the population"; exit 2; }
[ "$tb" = 0 ] && { echo "GATE OK [test_gate_no_rsp_reset_at_beta]: no beta resets rsp in $tp programs"; exit 0; }
echo "GATE FAIL [test_gate_no_rsp_reset_at_beta]: $tb beta reset(s) of rsp"; exit 1
```

A design step harness grading one witness in both modes, `test_design_unicon_steps.sh` 59-69: mode 3 in process, mode 4 compiled, assembled and linked the harness's way (PIE, `-lscrip_rt`, the rpath), each byte-equal to its `.ref` with rc 0, the reds named by mode and witness.

```bash
for w in $wits; do
    n=$((n + 1)); src="$WD/$w.icn"; ref="$WD/$w.ref"; o="$OUT/step$step/$w"
    [ -f "$src" ] && [ -f "$ref" ] || refuse "witness $w has no .icn or .ref in $WD"
    ( cd "$WD" && timeout -k 5 60 "$SC/scrip" "$w.icn" < /dev/null > "$o.m3.out" 2> "$o.m3.err" ); rc=$?
    if [ "$rc" = 0 ] && cmp -s "$o.m3.out" "$ref"; then m3p=$((m3p + 1)); else reds="$reds m3:$w(rc$rc)"; fi
    if ( cd "$WD" && timeout -k 5 120 "$SC/scrip" --compile --out="$o.s" "$w.icn" < /dev/null > /dev/null 2> "$o.m4c.err" ) \
       && gcc -c "$o.s" -o "$o.o" 2> /dev/null && gcc "$o.o" -L"$SC/out" -lscrip_rt -lm -lpthread -Wl,-rpath,"$SC/out" -o "$o.bin" 2> /dev/null; then
        ( cd "$WD" && timeout -k 5 60 "$o.bin" < /dev/null > "$o.m4.out" 2> "$o.m4.err" ); rc=$?
        if [ "$rc" = 0 ] && cmp -s "$o.m4.out" "$ref"; then m4p=$((m4p + 1)); else reds="$reds m4:$w(rc$rc)"; fi
    else reds="$reds m4:$w(no-build)"; fi
done
```

## 4. THE PROVING INSTRUMENTS (harness/scripts)

- For a new gate: run it on the tree where it should be red (the commit before the cure, or a corrupted copy of the ref in a scratch worktree) and on the tree where it is green; `util_require_fresh.sh` on line 2; a board line; `util_gate_wiring.py adopt` in the same landing (and the Makefile line if it joins the blocking set); `test_gate_preflight_arms_stay_cheap.sh` if the gate joins `preflight_arms.txt`; `test_gate_template_watch_names_a_planted_violation_by_commit.sh` is the model of a gate proven on a planted commit in a scratch repo, never in the tree.
- For a new witness: `util_add_ladder_witness.py` (a rung) or the design folder with `STEPS.tsv`; the ref cut twice from the oracle through its accessor; `corpus_suite_harness.py run ... --modes m3,m4 --partition entry:<name>`; `util_suite_partition.py build` when `ALL.csv` changed; `git add` the `.ref` as the binary it is.
- For a new design harness: clone the newest `test_design_*_steps.sh`, change `WD`, the extension, the probes; `--list` is the row's DONE-WHEN; every step's reading today goes on the ARCH page.
- For the lander's proof: `test_feature_reps.sh <lang> <feature>` (`--entries` needs a feature every named entry carries), `test_smoke_<lang>.sh`, `s4e_test_request.sh <suite-key> <entry>...` for the coo's verdict by telegram; `handoff_status.sh` pasted verbatim at the hand-off.
- The bracket for a red: `monitor_run.sh <prog> --oracle` (the bug lies between the last event both agree on and the first they diverge on), ASM-DIFF-FIRST beside a passing sibling within one mode, gdb last with a breakpoint and a hit count; validate an instrument by running it; a null result bounds the probe.

## 5. THE FORBIDDEN FORMS

A test edited to exit 0; an `xfail` cell set to 1; a prose DONE-WHEN, or one that pins a count (`== 274`), or one a deletion satisfies (`! grep -q defect`), or one without `S4E_HOME`; a planted seam in `src/` so a gate can trip; a gate with no refusal arm (a missing binary graded as a pass or a fail); a gate anchored on one found witness; a board run by a seat that is not the runner, or a suite table row written by anyone but the coo; a ref cut from the other mode, from a `.std` alone, or from a bare oracle path; a run without `timeout -k 5`, without `< /dev/null` when it reads no stdin, or with `< /dev/null` on a piped run; `SCRIP_HEAP_KB` or any environment size knob in a runner (the row's `-d`/`-s`); outputs under the root (proof dumps die in `/tmp`); a reading from a `-dirty` tree; a worktree without its harness and corpus siblings; a symlink; `pkill -f`; a `grep -q` pipe under `pipefail` (drain with `grep >/dev/null`); a `python3 - <<EOF` that reads stdin from a pipe (the heredoc eats it); a measurement loop writing outputs to `/tmp` while the box is busy; a clock outside `util_quiet_slice.sh`; `util_instr_count.sh` called with a pipe or socket stdin (it drains stdin to its end and the caller hangs: `< /dev/null` unless the program reads stdin; hq_jvm 2026-10-31).

## 8. THE INSTRUMENT LAWS (moved here from RULES.md on 2026-11-11, when Lon ruled that the skills are the law)


**Method**
- A red whose language has an instrumented oracle is bracketed: `monitor_run.sh <prog> --oracle` gives the last agreed event and the first divergence, and the bug is in what SCRIP executes between them (gdb breakpoint at the last-agreed emission, step to the next, or a trace across the pair). It does not apply when the wrapper refuses because tracing changes the output, the oracle cannot run the program, SCRIP dies before the first event, the monitor agrees on a program the suite grades red, or the divergence is mode 3 against mode 4; then use the asm diff.
- A bisect answers "which commit changed the observable", not "which commit is wrong"; a sound bisect onto a diff that cannot explain the failure is a latent defect plus a layout or timing perturbation, to be marked where the next author will trip on it.
- An asymmetry says there are two paths, not which two: name the carrier with a watchpoint on the storage before naming a mechanism.
- When every audit reads clean, sample the change (before and after one operation, two arrivals at one join), not the states; a defect can live in a transition.
- Name the machine state (load) beside a result whether or not it helped; when a confound lifts, split the question rather than harvest the cleaner conditions.
- Measure a correction at least as carefully as the claim it corrects, and show the command and unit.

**What an instrument must say**
- State the question the instrument decides before quoting its answer (`command -v` decides on-PATH, `bash -n` parseable, `ls | head` some-exist); ask what would look different if the stated reason were false.
- Measured-and-clean and never-ran print differently; "zero found" and "zero examined" print identically, so a null is trusted only from an instrument shown to produce a non-null on the same population, and a zero in a summary is an assertion: count misses where they happen or print no zero.
- Every grader states its denominator; PASS+FAIL must cover it. Read SKIP and CRASH before FAIL (a compile failure recorded as SKIP leaves FAIL=0). A zero denominator, or fewer inputs than a gate names, exits non-zero; `[ -f f ] && run` with no else disguises a skip as care. A standing refusal carries a re-point or a written reason to stand.
- State the population beside every verdict; an audit reports how many subjects it could not resolve (non-zero refuses), which needs a population enumerable independently of the resolution step, else the census is a labelled floor and no ruling cites it as a total.
- Print the reference value beside the measured one, and the names behind a total (`SUITE_LIST_ALL=1` lifts the 40-line cap).
- Compare two readings by denominator, SKIP count and entry names in both directions; two readings can agree on a count and differ in membership.
- An unknown argument is a refusal naming the real mechanism, never ignored; after a refusal compare the verdict line, not the artifact.
- A refusal that recurs is re-derived from the instrument, never from the last explanation; a refusal is never closed by attributing it to another lane. Diagnose a refusal to exhaustion (one rc 2 hides many causes).
- A rc is not a measure of time: a verdict that turns on duration records the duration. A truncated run proves a red it saw, never a green; rc 124 is never folded into a refusal before the verdict.
- Keep a bucket nameable: every printed count answers "name one member", and a number not to be quoted as a defect count stays inside its qualifying sentence.
- Success-shaped empty output (an empty tree, `md5("")`) is never graded as a pass; a bake step asserts its output is non-trivial.

**Proving an instrument**
- A new format is when strictness is free. Fail-once covers any field a human reads as state (a column no verb writes is unwritten, not stale), and the arms you write are the ones you thought of: ask whether the file's most natural content trips the leniency.
- Before trusting a negative, run a positive control that must fire and a negative that must not, against the instrument itself; prove the instrument can see the event (a witness that maximises it moves the counter); instrument both of two symmetric arms; a plant-proved instrument is evidence only for the defect the planter understood.
- A control arm licenses only the population convention it ran on (owe one per convention); a census that indicts 100 percent of its population is reporting on itself.
- A gate pins the property, never the mechanism (a retired ratio guard went green with honest counters), and its positive arm must be able to go red when the property is absent.
- A gate pins a message's meaning, never its spelling: read an error number as a whole-word token and negative-test the superstring (`2160`); a commit changing a message shape names every gate grepping it, on the bus too.
- A check whose subject is a refusal matches the refusal's own sentence plus a positive marker from the path it should have reached; a gate claiming N checks prints N verdict lines.
- A counter updated in a function on the right of a pipe is lost; use the gate's own shell, print `examined=N`, and treat a violation printed beside `examined 0` as a lost counter. In bash, an undefined function returns 127 and silently answers no: prove a verdict-driving predicate returns yes once in the same run.
- The instrument that can see a cure lands with or before it; a cure behind a flag defaults ON with the flag as the control arm, both arms boarded, and a bypass such as `SCRIP_OPT=0` is not a control unless it is a correct path; a measurement path is disjoint from the measured one or reports its perturbation.
- Extract by a line's identity and whole-word boundaries, not position; a count-based criterion anchors on regression, not `PASS >= N`; a cure named for a concept is graded on every spelling the noun covers; an all-clear names the list it ran and the campaign's own program is on it.
- Census patterns over emitted text are byte-safe (labels carry literal Greek alpha and beta); `grep -a` before believing an absence in an `ALL.ref` (one NUL makes it "binary"); when the source language defeats a regex (token pasting) the census runs the preprocessor.
- A comment relating two sites cannot be kept true by either file, and a stated cause expires toward work already done: bombs and refusals print the measurement first, the belief second, and both sides of a relationship are printable from one command.
- A gate or hold carries the condition that discharges it, written where the waiter stands.
- A tool that rebuilds elsewhere to detect drift reports clean first on a tree known current (`.file` carries the absolute path); sides built at different paths compare the path. A hand repro that drops the harness's environment (`SNO_LIB`, cwd, companion files) is a different program; build the population the grader builds, through the grader's own function.
- A committed test no denominator contains is worse than an xfail: keep a floor-only-falls census of orphans, matching membership by substring because absorbed files are renamed `<origin>__<name>`.
- A bounded cooperating set bounds the coordinator too; an exit trap that deletes scratch deletes the evidence; judge a tool on a witness that can exercise it.

**Landing proof**
- Boards in a commit bind the pushed tree: any later edit voids the quote; compile-check the edited unit and diff the landing site of every replace-all or whole-file write.
- A retraction greps the claim's noun across neighbour pages, batons, script headers and printed diagnostics in the same sitting, and says "retracted".
- A shared-node change (barrier templates, IR_BOUND, the collector, the zetas) carries the blocking set run gate by gate on base and head in a worktree, every non-green arm attributed; a head-only red is the change's. A control for your own gate is proved by reintroducing the defect.
- The wiring check runs again after the last file is staged, not after the last cure.
- A cure is measured base versus head on one origin tree (by rate when intermittent: N at least 5 runs per mode, count printed, refuse when the witness will not build) and re-proved after a rebase. Before attributing a moved cell to a cure, count whether the cured code runs in that program; re-draw any name seen on one side only; prove the population can move before reporting nothing moved.

**Collector measurements**
- A knob is a request, collections are the evidence: every GC gate reads `collections` from its own `[GC-EXERCISE]` line and refuses at zero, and every GC verdict prints how many arms collected. A failing witness first gets the zero-collection arm (stress 0, `collections=0`): fails there is emission, clean there and fails once a collection runs is collector.
- Stress is a band, never a point: both the aggressive and the sparse ends, each point printing its collector count (inert refuses), the verdict a name set per point, published as "lower bound clean". Windows can be ragged, higher stress is cheaper, and a stress-pinned ceiling is calibrated per witness at a named collection count.
- A safe-point insertion is cleared only by identical non-green name sets against a clean-tree control on the identical set under forced relocation; no proxy (return class, quick sweep, static register reader) clears a site. A root census excludes a register only by a declaration in the tree that says where it points.
- The tiny arena is a second pass (`make test-arena`, `SCRIP_HEAP_KB_TINY`), not the blocking set's environment; a landing gate and a suite row grade the shipped arena, every board line names its arena, and each red the tiny pass finds is a row. No arena is the harshest: when the live set fits a smaller window collects more, when it does not the window grows (`grew`) and the point is not measuring the arena it names. A `heap exhausted at the reserve cap` abort is classified by window and cap before it is rowed.
- A collector name set depends on the invocation (the argv string is an allocation; path spelling and length shift which allocation a forced collection lands on): publish the invocation beside the name set unless path-invariance was measured.
